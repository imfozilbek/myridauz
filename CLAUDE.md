# Rida — правила для Claude

## Язык и стиль ответов

- Отвечать пользователю **только на русском языке**.
- Ответы должны быть внятными, чёткими и по делу. Без воды.
- Писать так, чтобы понял человек, для которого русский **не родной язык**:
  - короткие предложения, одна мысль — одно предложение;
  - простые, частые слова; без идиом, сленга и сложных оборотов;
  - технический термин — с коротким пояснением при первом упоминании.
- Каждый ответ проходит через призму **cognitive ease** (когнитивная лёгкость):
  - главное — в первой строке;
  - структура: заголовки, списки, таблицы вместо длинных абзацев;
  - минимум вариантов: одна рекомендация, а не список из всех возможных;
  - понятный следующий шаг в конце, если он нужен.

## О проекте

- **Rida** — сервис междугородних поездок (ride sharing) по всему Узбекистану.
- Домен: `myrida.uz`.
- Продукт: Telegram-бот, Telegram Mini App, каналы; лендинг — в конце.
- Язык интерфейса продукта: **только узбекский**.
- Инфраструктура: **только бесплатные ресурсы**, в приоритете Cloudflare
  (Workers, Pages, D1, KV, R2).
- Заработок — с водителей. Сервис не вмешивается в договорённости
  между водителем и пассажиром.

## Ключевые фичи

- **«В машине есть женщина»** — одна из главных фич.
  - При регистрации каждый пользователь указывает пол.
  - Отметка у поездки ставится **автоматически**, если:
    1. водитель — женщина, или
    2. женщина забронировала место (бронь подтверждена), или
    3. водитель вручную отметил, что в машине едет женщина
       (например, родственница, которая не пользуется ботом).
  - Если бронь женщины отменена и других причин нет — отметка снимается.
  - Пассажиры видят отметку и могут фильтровать поездки по ней.
  - Показываем только факт «в машине есть женщина», без имени и данных.

- **Контакты скрыты до договорённости.**
  - Пассажир и водитель не видят телефон и @username друг друга.
  - Общение — через анонимный чат внутри Rida.
  - Контакты открываются только после того, как водитель подтвердил бронь.
- **Анонимный чат в реальном времени — внутри Mini App, на Cloudflare.**
  - Cloudflare Durable Objects (SQLite) + WebSocket Hibernation API:
    один Durable Object = один чат (одна бронь).
  - Если Mini App закрыт — бот присылает уведомление о новом сообщении
    с кнопкой «открыть чат».
- **Голосовой звонок в реальном времени — внутри Mini App, на Cloudflare.**
  - WebRTC + Cloudflare Realtime SFU (TURN включён).
  - Сигнализация (кто звонит, принять/отклонить) — через тот же Durable Object чата.
  - Если Mini App закрыт — бот присылает «Вам звонят» с кнопкой «ответить».
  - Номера телефонов при звонке не раскрываются.
  - Перед основной разработкой — прототип и проверка на реальных
    телефонах (Android и iOS).
