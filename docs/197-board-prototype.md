# 197. Прототип доски: скрипты сессии 18 … 19.10.2026

## Кратко

- Папка `scripts/doska/`: прототип цепочки «экспорт группы → разбор → посты доски → канал → бот карточек».
  На нём проверена логика `196` на группе Yakkabogʻ Toshkent: 25 929 сообщений за сутки, 23 тыс. участников,
  804 автора, около 600 уникальных поездок.
- Это исследовательский код на Python, не продукт. Три файла длиннее 150 строк (`rida_matn.py` 268,
  `rida_tahlil.py` 279, `rida_doska.py` 191): отступление от `11`, принято как прототип. В продукт идёт
  переписанным на TypeScript отдельной целью.
- В репозитории нет: токена бота, экспорта группы, файлов с номерами, журналов, ссылок-приглашений.
  Всё это в папке данных вне репозитория: переменная `DOSKA_DATA` (по умолчанию `./data`, в `.gitignore`).

## Что делает каждый файл

| Файл | Что делает |
|---|---|
| `rida_html.py` | Читает экспорт Telegram Desktop (HTML): сообщения, автор, дата, пересылки |
| `rida_matn.py` | Чистит узбекский текст, достаёт поля: откуда, куда, когда, места, машина, почта, роль, спам |
| `rida_tahlil.py` | Собирает людей и таблицы, пишет Excel анализа (13 листов) |
| `rida_xlsx.py` | Минимальный писатель `.xlsx` без зависимостей, ссылки с подписью |
| `rida_doska.py` | Сутки как окна доски: строка машины, блоки SROCHNO / BUGUN / ERTAGA, маскированный номер |
| `rida_oynalar.py` | Три поста окна: ERTAGA, направление 1, направление 2; раскрывающиеся цитаты |
| `rida_haydovchilar.py`, `rida_uch_ustun.py` | Excel водителей: номера, ссылки Telegram по номеру и по ID; три колонки |
| `tg_post.py` | Вызов Bot API, первая публикация постов и закреп |
| `tg_window_edit.py` | Правка трёх постов на месте: текст и кнопки (Haydovchiman, Doʻstga yuborish, навигация) |
| `tg_invites.py` | Именованные ссылки-приглашения по источникам (пересылка, салон, местный канал, реклама) |
| `tg_bot_profile.py` | Экран бота до Start: описание и короткое описание |
| `tg_bot.py` | Тестовый ответчик: Start, карточка по 📞 (текст водителя, кнопка copy_text, контакт), лимит 10 в час |
| `sampler.sh` | Замер онлайна группы каждые 5 минут в CSV |
| `tg_stats.py` | Участники, онлайн и посты в сутки по публичным страницам t.me |

## Как запустить

```
export DOSKA_DATA=/путь/к/данным     # token, all/chat/*.html, выходные файлы
cd scripts/doska
python3 rida_tahlil.py $DOSKA_DATA/all/chat $DOSKA_DATA/Rida_tahlil.xlsx
python3 rida_oynalar.py $DOSKA_DATA/all/chat $DOSKA_DATA/window
python3 tg_invites.py $DOSKA_DATA/token $DOSKA_DATA/invites.json
python3 tg_window_edit.py $DOSKA_DATA/token $DOSKA_DATA/window
python3 tg_bot.py $DOSKA_DATA/token $DOSKA_DATA/bot_log.csv $DOSKA_DATA/all/chat
./sampler.sh Taksi_xizmatiii
```

Номера постов канала и имя канала заданы в `tg_window_edit.py` и `tg_bot.py` (тестовый канал `@yakkabog_rida`).
