## C. Не хватает данных на экране

- Попутчик: нет числа предложений на карточке заявки; нет рейтинга водителя в предложении; нет причины, если поездка из канала закрыта; оценку можно дать только из бота; точку посадки можно задать только ответом боту.
- Водитель: нет баланса на экране подтверждения; нет «N ta soʻrov kutmoqda» и срока ответа; точка посадки попутчика не приходит; нельзя изменить поездку с бронями; «Hamyon» показывает уже сгоревший бонус.
- Команда: нет истории прошлых заявок водителя и проверки повторного номера машины; мало данных в жалобе (маршрут, посадка, отметки); нет журнала «кто заблокировал и почему»; нет разблокировки.

## D. Надёжность и нагрузка

- Все 10 задач Cron в одном запуске: при ~20 водителях упираются в лимит запросов бесплатного тарифа.
- Сообщения: ошибка очереди после записи в базу даёт человеку «ошибку», хотя действие прошло; повтор шлёт дубли; нет очереди для упавших сообщений.
- Сеть: нет таймаута запросов, повтор после таймаута создаёт дубли; тихое обновление не показывает «данные устарели»; после 24 часов вход истекает молча.
- Живой канал (G19): после переподключения нет догоняющего обновления; изменения из Cron (просрочка, завершение) сигнала не дают.

## Решения владельца (30.09.2026)

- Пост «Mashinada ayol bor» в каналах **остаётся** (`06`).
- Модератор **видит** кошельки водителей. Менять кошелёк может только владелец. Из A6 остаются цены, расстояния и каналы: только владелец.
