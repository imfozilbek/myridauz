# 223. Карточки Mini App в группе направления: вид группы и знак R

> **Кратко:** решение владельца 05.11.2026 («Да, кириллица, Premium есть»): поездки водителей и заявки пассажиров из Mini App идут в группу `@yakkabog_toshkent_rida` в виде карточек самой группы, кириллицей. У каждой знак R своего вида: янтарный «Mini App» у поездки, бирюзовый «Mini App» у заявки. Каналы направлений не меняются. Цель: G94.

## Решение владельца

- 05.11.2026, по снимку группы: «Карточки от мини аппа тоже превратились на карточки группы… Нам нужно чтобы еще 2 вида R появились которые показывают что карточка из мини аппов (водителя и пассажира)».
- Макет (`H/r_app/r_app.png` сессии данных): «Да, кириллица, Premium есть».
- Premium у владельца бота: свои эмодзи (знак R) бот может ставить в группе. Без Premium Telegram покажет запасной значок 🟧 или 🟦.

## Карточка поездки

| Строка | Пример (латиница в каталоге, в группе кириллица) |
|---|---|
| Голова + R янтарный | `🚗 BOʻSH Gentra · Yakkabogʻga`; есть брони: `🚗 OLIB KETAMAN · Yakkabogʻga` |
| Проверка | `✅ Tekshirilgan · 🆕 Yangi haydovchi` или `⭐ 4,8` |
| Откуда | `📍 Yunusoboddan (Toshkent shahri), uyingizdan`; пятак: `{пятак}dan`, оба: `… yoki uyingizdan` |
| Куда | `🏁 Yakkabogʻgacha, uyingizgacha` |
| Время | `🕒 Bugun 16:00 da yoʻlga chiqadi, ≈ 23:05 da yetadi`; промежуток без «yetadi» (`216`) |
| Места | `💺 4 ta boʻsh joy · 💰 160 000`; одно место: `🔥 1 ta joy qoldi · 💰 160 000` |
| Женщина | `👩 Mashinada ayol bor` (как в канале) |
| Кнопка | `💺 Joy band qilish`: бронь в боте пассажира с меткой группы (`116`) |

- «BOʻSH» при 4 свободных местах и больше, как у карточек группы (решение 25.10.2026).
- Модель машины всегда латиницей (решение 25.10.2026).
- Поздние состояния («Joy qolmadi», «Yoʻlga chiqdi», «Yetib bordi», отмена) прежние тексты `154`, в группе кириллицей.

## Карточка заявки (новое)

| Строка | Пример |
|---|---|
| Голова + R бирюзовый | `🙋 MASHINA KERAK · Yunusoboddan`; 4 человека или весь салон: `🙋 BOʻSH MASHINA KERAK · …` |
| Куда | `🏁 Kitobga ketaman` |
| День | `🕒 Ertaga, 6-noyabr` |
| Люди и цена | `🧍 2 kishi · 💰 150 000` |
| Кнопка | `🙋 Yoʻlovchini olish`: заявки маршрута и дня в боте водителя (`83` N08); знак руки, как в голове заявки |

- Отличие от макета: у заявки нет часа, только день (так хранит Mini App). Поэтому строка `🕒` без времени.
- Добавлена цена за место: водитель решает по ней. Если не нужна, уберём.
- Имени и телефона нет: контакты не раскрываются (`07`).
- 06.11.2026 владелец по снимку группы: «карточка из постера выглядит как машина водителя». Причина: 🚘 на кнопке. Теперь 🙋: у заявки рука, у поездки машина (урок №385).

## Жизнь поста заявки

| Событие | Что делает бот каналов |
|---|---|
| Заявка опубликована | Пост без звука во все группы маршрута (только группы, не каналы) |
| Отменена, истекла, принято предложение водителя | Правка `✅ Yoʻlovchi soʻrovi yopildi`, затем удаление |
| Пост старше 48 часов | Telegram не даёт удалить: остаются слова о закрытии |
| Закрылась, пока пост ждал в очереди | Закрывается сразу после отправки |

- Номера постов: таблица `request_posts` (миграция 0087).
- Жалобы скрыли пассажира (`17`): его заявка в группу не идёт.

## Где в коде

| Что | Файл |
|---|---|
| Латиница в кириллицу | `packages/i18n/src/cyrillic.ts` (как `cyr.py` доски) |
| Окончание «-ga», «-gacha» (k, q) | `packages/i18n/src/place-end.ts`, каталог `bot-group.json` |
| Вид группы в бренде | `groupCards` в `brands/rida/brand.config.ts` (знаки R, кириллица) |
| Карточка поездки | `channels/infrastructure/group-trip.ts` |
| Карточка заявки, закрытие | `channels/infrastructure/group-request.ts`, `application/request-posts.ts` |
| Связи модулей | `src/request-events.ts` |

- Бренд без `groupCards`: группа получает пост канала, заявок там нет (`22`).
