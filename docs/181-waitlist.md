# 181. Список ожидания: заявки заранее от попутчика и водителя (G83)

> **Кратко:** решение владельца 14.10.2026. До открытия поездок человек не видит пустой поиск. Один новый бот «MyRida» (`@myridauz_bot`) и его Mini App: человек выбирает роль, **свои боли** (v2), направление и «когда»; видит, как Rida решает именно его боли, и «Tez orada»; получает канал «MyRida | Oʻzbekiston». Обе стороны говорят заранее: попутчик «я поеду», водитель «я повезу». Команда видит, сколько людей ждёт на каждом направлении, и открывает направление, когда там есть водители: бот пишет всем, кто ждёт. Макеты: `goals/g83`, тексты: `182`. План: запуск списка 18.10.2026.

## Зачем

| Проблема | Как решает список |
|---|---|
| Поиск без поездок: человек уходит навсегда (`40`, исследование 13.10.2026) | До открытия направления человек не ищет, а ждёт; бот пишет, когда поездки есть |
| Неизвестно, где нужны водители | Счётчик «Kutayotganlar» по направлениям: попутчики, водители, «когда» |
| Нет связи с людьми до запуска | Бот может написать каждому, кто нажал Start |
| Водители приходят последними | Водитель сразу идёт на проверку в бот водителя (G62) |

Слово «предзаказ» не используем (урок №2): в продукте и документах «заявка заранее».

**Бот по системе G68 (`122`, решение владельца 14.10.2026):** одна сущность = одна карточка; изменения правят её без звука (раз в неделю: сколько ждут); о действии самого человека не пишем, поэтому отдельного «Siz roʻyxatdasiz» нет; звук только при открытии направления. Ночного режима без звука в этом боте нет (решение владельца 14.10.2026): звонок один, его шлёт команда кнопкой «Ochish» в своё время работы.

- Телефон не спрашиваем: хватает Telegram ID. Меньше шагов.
- Выбор, а не ввод: ни одного поля для текста.
- Кнопки внизу экрана результата: попутчик «Doʻstimni chaqiraman» и «Kanalga qoʻshilish»; водитель «Tekshiruvdan oʻtish» и «Doʻstimni chaqiraman».
- «Oʻzgartirish» открывает шторку: направление, «когда», вторая роль, «Roʻyxatdan chiqish» (`3-result` 4, 5).

- Правила рекламы (хаб команды): без слова «taksi», без «tekshirilgan haydovchi» (документы не проверяются), без цен и бонусов без согласия, без сравнения с конкурентами. Поэтому в v2 нет «Bu taksi emas», «Haydovchilar tekshirilgan», кнопка водителя «Haydovchi boʻlish».

## Правила

| Правило | Почему |
|---|---|
| Счётчик «Bu yoʻnalishda N kishi kutmoqda» только при N от 10 | Пустой счётчик отпугивает; цифры только настоящие (урок №9) |
| Нет «вы 345-й в очереди» и закрытого доступа | Закрытый доступ почти не работает (исследование, NFX) |
| Бот пишет лично только по большому поводу, не чаще 1 раза в неделю; ночного режима без звука нет | Как `122`: человек не устаёт |
| Одна запись на роль; можно изменить; «Roʻyxatdan chiqish» стирает запись | Как удаление данных `58` |
| Ссылка «Doʻstimni chaqiraman» с меткой `via` и кодом автора | Видно, кто кого привёл (`116`) |
| Тексты только по ключам, на согласие владельца, проверка носителем | `25`, `13` |

## Команда (`4-admin`)

- «Statistika» → новый блок «Kutayotganlar»: всего попутчиков и водителей; направления (пара областей) по числу ждущих.
- Экран направления: попутчики по «когда», **доля каждой боли** (полоски), водители по «когда» и болям, сколько заявок одобрено.
- В блоке «Kutayotganlar» строка «Eng koʻp ogʻriq»: самая частая боль и её доля.
- «Yoʻnalishni ochish»: шторка с числом людей; бот пишет всем один раз; в строке «Ochildi · дата» и «Xabar ketdi: N kishiga».

## Каналы

- Пока идёт список, канал один: главный канал своей среды; во внутренней `@myrida_uz` «MyRida | Oʻzbekiston», не `@rida1uz` из прода (решение владельца 14.10.2026). Туда ведут кнопка бота и «Kanalga qoʻshilish».
- Каналы направлений (`176`) человек получает, когда его направление открыто: кнопка «Yoʻnalish kanali» в сообщении «Yoʻnalishingiz ochildi» (решение владельца 14.10.2026). Во внутренней среде это «MyRida | Viloyatlar», в проде свой канал места (`channelOf`). Пустой канал без поездок не зовём.
- На экране результата канал среды стоит карточкой: «Qoʻshilish» или «✓ Aʼzosiz» (бот каналов знает, кто вступил, `chat_member`, G80).
- Где зовём в канал: приветствие бота («Kanalimiz»), пост после опросника, карточка на результате, «Yoʻnalishingiz ochildi».
- Анонсы в каналах 2 раза в неделю, только реальные новости (например, сколько водителей прошло проверку). Первые 4 текста на согласие владельца.
