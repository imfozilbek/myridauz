# 83. Находки G27: ошибки и упущения

> **Кратко:** что нашлось при составлении каталога (`76` … `82`) и на стенде. Каждая находка сначала проверяется на стенде. Подтвердилась ошибка: падающий тест, исправление, урок. Упущение или вопрос UX: предложение владельцу, делается после согласия.

## Статусы

| Статус | Значит |
|---|---|
| Проверить | Кандидат из кода, ещё не воспроизведён |
| Подтверждена | Воспроизведена на стенде или тестом |
| Исправлена | Есть тест, исправление и урок |
| Владельцу | Нужно решение владельца |
| Снята | Не подтвердилась |
