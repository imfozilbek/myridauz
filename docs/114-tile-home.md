# 114. Главный экран плитками (G53)

> **Кратко:** владелец выбрал вид главных экранов 04.10.2026: попутчик A, водитель A, админка C (снимки макетов в цели G53). Действия стали плитками по две в ряд. Плитка говорит живое: счётчик того, что ждёт человека, или цифру дня. Блок сверху (ближайшие брони и поездки) остался.

## Попутчик: вариант A

| Место | Что показывает | Куда ведёт |
|---|---|---|
| Сверху | Ближайшие брони; заявки, где водители прислали предложения («2 ta taklif») | Бронь; первое предложение заявки |
| Сверху, если ничего нет | «Qayerdan / Qayerga borasiz?» | Поиск |
| Плитка «Soʻrov qoldirish» | Счётчик предложений без ответа | Новая заявка |
| Плитка «Mening safarlarim» | Счётчик живых броней | Мои поездки |
| Плитка «Oxirgi yoʻnalish» | Последний маршрут поиска | Результаты этого маршрута |
| Плитка «Profil» | «Rasm va sozlamalar» | Профиль |

- «Safar topish»: главная кнопка Telegram, плиткой не повторяется.
- Без маршрута в памяти «Profil» занимает весь ряд.
- Список «Oldingi yoʻnalishlar» заменила одна плитка «Oxirgi yoʻnalish».

## Водитель: вариант A

| Плитка | До одобрения | После одобрения |
|---|---|---|
| «Safar eʼlon qilish» | «Tekshiruvdan keyin» | Плитка и главная кнопка |
| «Yoʻlovchilar soʻrovlari» | «Yoʻnalishingizdagi», экран сам объясняет ожидание | Поиск заявок |
| «Mening safarlarim» | Мои поездки | Счётчик новых запросов на живых поездках |
| Четвёртая | «Yordam»: бот поддержки | «Hamyon»: бонус или баланс |

- Сверху: заявка или «Arizangiz tekshirilmoqda», ближайшие поездки. Без поездок сверху пусто, как на макете; если водитель уже ездил, есть карточка «Oxirgi yoʻnalish» (повтор в одно касание, G40 K3).
- Счётчика на «Yoʻlovchilar soʻrovlari» нет: заявки ищут по маршруту и дню, общего числа «для водителя» у сервера нет.

## Админка: вариант C

| Плитка | Цифра | Куда ведёт |
|---|---|---|
| «Arizalar» | Сколько ждут; красная, если больше 0 | Заявки водителей |
| «Shikoyatlar» | Сколько новых; красная, если больше 0 | Жалобы |
| «Bugun» | Новые люди за день | Статистика за день |
| «Safarlar» | Живые объявления сейчас («faol eʼlon»): активные и полные поездки, которые ещё не уехали | Поездки команды |

- Каждая плитка грузит свои данные сама: сбой одной не прячет другие.
- Ссылка бота на статистику открывает «Boshqaruv», как раньше.

## Вид (как на макетах)

- Серый фон, белые карточки с круглыми углами, 16px от краёв.
- Профиль: имя и роль («Yoʻlovchi», «Haydovchi · Cobalt, oq», «Egasi»). Админка берёт имя и роль с `GET /admin/me`.
- Поездка: «A › B» с зелёной и красной точкой, время, плашка статуса (зелёная «готово», янтарная «ждёт»). Цвета `success`, `attention` (`20`).
- Иконки плиток: цветная иконка на светлом фоне того же цвета.
- «Ariza tekshirilmoqda»: янтарная карточка с часами, без «Yopish», пока идёт проверка.
- Размеры и цвета взяты из исходника макета: отступ 12px, плитка 14px внутри, иконка 40px на светлом фоне, счётчик круг 22px, плашка 12.5px.
- Плашки «1 xabar» с макета нет: число непрочитанных сообщений сервер пока не отдаёт.
- Счётчика «4» на «Yoʻlovchilar soʻrovlari» нет: общего числа заявок для водителя у сервера нет.

## Как устроено

- `HomeTile` (`packages/ui/src/flow/home-tile.tsx`): иконка, заголовок, подсказка, счётчик или цифра.
- Действие говорит живое через `useLive` (`start-action.ts`).
- Данные главного экрана грузятся один раз: `PassengerData`, `DriverData`. Блок сверху и счётчики читают одно и то же.
- Разделы, которые открывает только плитка: `sections` в `StartFlow`.
- Тексты на согласие владельца: `home.json` (`profileHint`, `support`, `supportHint`, `walletBonus`, `admin.*`, `role.*`).
