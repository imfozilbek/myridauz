# 88. Улучшения UX и UI из наших библиотек

> **Кратко:** список того, что можно сделать лучше готовыми элементами TelegramUI 2.1, Telegram SDK и Lucide (`docs/19`, `docs/21`). Своё не рисуем: только то, что уже есть в библиотеках. Сначала самое важное. Это предложения: вид экранов меняем только после согласия владельца (`docs/33`). Собрано 02.10.2026 по коду и скриншотам стенда (`screenshots/stand/g27`).

## Что есть и что используем

| Библиотека | Используем | Есть, но не используем |
|---|---|---|
| TelegramUI | Cell, Section, List, Button, Input, Switch (2 места), SegmentedControl, Multiselectable, Badge, Skeleton, Placeholder, Text, Title, Caption | Textarea, Steps, Progress, Timeline, Snackbar, Banner, IconButton, AvatarStack, Modal, Accordion, Chip, Rating, Checkbox, Spinner |
| Telegram SDK | MainButton, SecondaryButton, BackButton, popup, haptic (tap, success, error), closingBehavior, swipeBehavior, locationManager, shareMessage, цвета шапки и низа | haptic `selectionChanged`, CloudStorage, SettingsButton, addToHomeScreen, shareStory |
| Lucide | Иконки через `packages/ui/src/icons.tsx` | Иконки у строк фактов поездки (ayol bor, uydan olib ketadi) |

## Список (сначала самое важное)

| № | Где | Сейчас | Что взять | Польза |
|---|---|---|---|---|
| L1 | Профиль (pa11, da11) | Сообщения бота включаются только при регистрации, выключить нельзя | **Switch** «Bot xabarlari» (как iOS): `requestWriteAccess` при включении, API `setWriteAccess` уже есть | Человек сам решает; не блокирует бота целиком (N07 в `docs/86`) |
| L2 | Отзыв (pa23), жалоба (pa24), комментарий поездки (da45), чат (pa21) | Однострочный Input, подсказка обрезана «(ixt…» | **Textarea** с ростом по тексту | Видно весь текст и подсказку; длинный отзыв удобно писать |
| L3 | Все выборы: список, звёзды, Switch | Вибрация только на кнопках | haptic **selectionChanged** на каждый выбор | Ощущение родного Telegram на каждом касании (`docs/21`) |
| L4 | Заявка водителя (d21 … d26), новая поездка (da40 … da46), заявка попутчика | Человек не знает, сколько шагов осталось | **Progress** (тонкая полоса сверху) или **Steps** | Меньше бросают на середине: видно, что осталось 2 шага |

| L10 | Чат (pa21) | Кнопка текстом «Yuborish» | **IconButton** со стрелкой Lucide `Send` | Как в Telegram; больше места для текста |

## Что не меняем

| Элемент | Почему оставить как есть |
|---|---|
| Звёзды `StarsRow` вместо **Rating** | У нас крупнее касание и подписи 1 … 5: лучше для пожилых |
| Списки выбора (места, дата, цвет) вместо **Select** | Правило `docs/19`: выбирать в списке, а не в выпадающем меню |
| Вопрос «Mashinada ayol bormi?» отдельным шагом | Один экран: один вопрос; Switch нужен там, где уже есть другие строки |
| Свои `fact-chips` вместо **Chip** | Chip в TelegramUI для выбора; наши строки только показывают факты |

## Как делать

1. Владелец выбирает номера (ответ «L1, L2, L5 да»).
2. Каждый пункт: обёртка в `packages/ui/src/components.ts` (приложения берут TelegramUI только оттуда), падающий тест, скриншоты Android и iOS 360 px.
3. Новые тексты (L1, L7, L8, L14): на согласие и носителю (`docs/25`).
4. Без backend: L1 … L5, L7 … L11, L13 … L16, L18. С backend: L6 (время каждого статуса брони). С проверкой: L12 (перенос данных), L17 и L19 (поведение Telegram на разных телефонах).
