# 14. Локации и маршруты

> **Кратко:** Маршрут: регион и район → регион и район. Точки А и Б ставит попутчик на карте при брони (G24, `70`, `71`); водитель точек не ставит. Точную точку водитель видит только после подтверждения. Справочник, источники, расстояния и экран выбора: `48`.

## Как устроен рынок

- Основной поток: **город Ташкент ⇄ области**.
- Внутри области человек едет в конкретный район или местность.
- Поэтому маршрут всегда: **регион + район → регион + район**.

## Уровень 2: районы

- У каждого региона: свои районы (tuman).
- У города Ташкента: свои районы (Chilonzor, Yunusobod и т.д.).
- Города областного подчинения (например, Samarqand shahri, Chirchiq)
  тоже элемент уровня 2, тип `city`.
- Источник списка: официальный классификатор СОАТО.
  Код СОАТО = ID локации в базе.

## Поездок внутри города нет (решено)

- Rida только для поездок **между** населёнными пунктами.
- Нельзя создать поездку или заявку, если «откуда» и «куда»:
  1. один и тот же район или город уровня 2;
  2. оба внутри города Ташкента (районы Toshkent shahri считаются одним городом).
- Город Ташкент → Ташкентская область: можно (это уже другой населённый пункт).
- Ошибка показывается сразу при выборе «куда», текст через ключи перевода.

## Уровень 3: точная точка (адрес / геолокация)

- Где забрать и куда отвезти: **точка на карте**. Способ посадки: пятак, от двери или оба (`70`).
- **G24 (30.09.2026):** попутчик ставит А и Б на экране «Qayerdan / Qayerga» до поиска (`71`); бронь несёт способ и точки, после брони они не меняются. Водитель точек не ставит и пятак не выбирает: пятак направления берёт система (`72`).
- **Район точки** по границам OSM (`48`), не по ближайшему центру.
- **Приватность:** до подтверждения водитель видит окрестность («Qatortol atrofi») и «+N km»; точку после подтверждения; команда видит только окрестность. Хранение и стирание: `69`.
- **Решено (G22, 30.09.2026):** попутчик выбирает свою точку на карте внутри Mini App
  (своя карта OSM в R2, без внешних сервисов, `67`).
- **Поиск по названию (G23):** на карте можно найти махаллю, улицу или ориентир по-узбекски
  или по-русски, сначала рядом с городом отправления (`67`).
- Запасной путь без карты: «Roʻyxatdan tanlash» (регион → район), центр района вместо точки.
- Точки через бот больше не принимаются (G24): одно место выбора, одно место хранения.

## Модель данных

```
locations (id = код СОАТО, parent_id, type: region|district|city, lat, lng)
location_translations (location_id, locale, name)   # см. 13-i18n.md
trips / ride_requests:
  from_location_id, to_location_id                  # уровень 2
  pickup_mode: pitak | door | both                  # G24, `70`
ride_requests: pickup_lat/lng, dropoff_lat/lng      # пока заявка открыта
bookings:
  pickup_mode, pitak_id, pickup (lat, lng, name), dropoff (lat, lng, name)
pitaks, pitak_directions, pitak_log                 # `72`
```

## Поиск

- Пассажир выбирает: регион → район (или «весь регион»).
- Поиск по району показывает и поездки «весь регион».
- Рекомендованная цена считается по паре районов: `09-marketplace-and-pricing.md`.
