# 14. Локации и маршруты

## Как устроен рынок

- Основной поток: **город Ташкент ⇄ области**.
- Внутри области человек едет в конкретный район или местность.
- Поэтому маршрут всегда: **регион + район → регион + район**.

## Уровень 2: районы

- У каждого региона — свои районы (tuman).
- У города Ташкента — свои районы (Chilonzor, Yunusobod и т.д.).
- Города областного подчинения (например, Samarqand shahri, Chirchiq)
  — тоже элемент уровня 2, тип `city`.
- Источник списка — официальный классификатор СОАТО.
  Код СОАТО = ID локации в базе.

## Уровень 3: точная точка (адрес / геолокация)

- Где забрать и куда отвезти — **точная геолокация**.
- Указывается при создании поездки/заявки или при договорённости в чате.
- **Приватность:** точная точка видна другой стороне только после
  подтверждения брони. До брони — только регион и район.
- Способ (MVP): отправка локации через Telegram (встроенная карта Telegram,
  бесплатно, без внешних сервисов).
- Карта внутри Mini App — позже (нужен источник карт, см. открытые вопросы).

## Модель данных

```
locations (id = код СОАТО, parent_id, type: region|district|city, lat, lng)
location_translations (location_id, locale, name)   — см. 13-i18n.md
trips / ride_requests:
  from_location_id, to_location_id                  — уровень 2
  pickup_point (lat, lng, комментарий)              — уровень 3
  dropoff_point (lat, lng, комментарий)             — уровень 3
```

## Поиск

- Пассажир выбирает: регион → район (или «весь регион»).
- Поиск по району показывает и поездки «весь регион».
- Рекомендованная цена считается по паре районов — `09-marketplace-and-pricing.md`.
