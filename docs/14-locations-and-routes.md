# 14. Локации и маршруты

> **Кратко:** Маршрут: регион и район → регион и район. Точная точка через локацию Telegram, видна только после брони.

## Как устроен рынок

- Основной поток: **город Ташкент ⇄ области**.
- Внутри области человек едет в конкретный район или местность.
- Поэтому маршрут всегда: **регион + район → регион + район**.

## Уровень 2: районы

- У каждого региона: свои районы (tuman).
- У города Ташкента: свои районы (Chilonzor, Yunusobod и т.д.).
- Города областного подчинения (например, Samarqand shahri, Chirchiq)
  тоже элемент уровня 2, тип `city`.
- Источник списка: официальный классификатор СОАТО.
  Код СОАТО = ID локации в базе.

## Поездок внутри города нет (решено)

- Rida только для поездок **между** населёнными пунктами.
- Нельзя создать поездку или заявку, если «откуда» и «куда»:
  1. один и тот же район или город уровня 2;
  2. оба внутри города Ташкента (районы Toshkent shahri считаются одним городом).
- Город Ташкент → Ташкентская область: можно (это уже другой населённый пункт).
- Ошибка показывается сразу при выборе «куда», текст через ключи перевода.

## Уровень 3: точная точка (адрес / геолокация)

- Где забрать и куда отвезти: **точная геолокация**.
- Общая точка встречи: при создании поездки. Свои точки: у каждой брони
  после подтверждения (`35`).
- **Приватность:** точная точка видна другой стороне только после
  подтверждения брони. До брони: только регион и район.
- **Решено:** точка передаётся через встроенную функцию Telegram
  «Отправить локацию» (карта Telegram, бесплатно, без внешних сервисов).
- Точку отправляют в бот; бот сохраняет её к поездке или брони.
- Карта внутри Mini App не сейчас. Вернуться к вопросу позже.

## Модель данных

```
locations (id = код СОАТО, parent_id, type: region|district|city, lat, lng)
location_translations (location_id, locale, name)   # см. 13-i18n.md
trips / ride_requests:
  from_location_id, to_location_id                  # уровень 2
  meeting_point (lat, lng, комментарий)             # общая точка поездки
bookings:
  pickup_point, dropoff_point (lat, lng, комментарий)  # у каждой брони (`35`)
```

## Поиск

- Пассажир выбирает: регион → район (или «весь регион»).
- Поиск по району показывает и поездки «весь регион».
- Рекомендованная цена считается по паре районов: `09-marketplace-and-pricing.md`.
