# 33. Согласие и проверка владельцем

> **Кратко:** Список того, что Claude не делает без согласия или проверки владельца. В каждой цели такие места отмечены отдельным блоком. Пока ждёт ответа, Claude продолжает всё, что от ответа не зависит.

## Правило (решение владельца)

- В некоторых местах нужно, чтобы владелец **посмотрел, проверил
  или дал согласие**. Claude такие места никогда не пропускает.
- В каждой цели (`goals/`) есть блок **«Проверка владельцем»**.
  Пункт «Владелец подтвердил» входит в Definition of Done.
- Пока владелец не ответил, Claude **не стоит на месте**: делает всё,
  что от ответа не зависит. Цель закрыта только после подтверждения.

## Всегда нужно согласие владельца

| Что | Почему |
|---|---|
| Слияние в `main` и деплой в прод | Прод видят реальные люди (`32`, `34`) |
| Необратимые действия: удаление данных, переписывание истории git, force push | Нельзя отменить |
| Публичные действия: посты в каналах, рассылки пользователям, профили ботов | Видят все |
| Изменение DNS и настроек домена | Может сломать сайт и ботов |
| Настройки GitHub: защита веток, Environment, доступы | Нужны права владельца |
| Деньги: комиссия, бонус, возвраты, цены по умолчанию | Бизнес-решение |
| Юридические документы перед публикацией (`30`) | Ответственность владельца |
| Узбекские тексты (`25`) | Владелец носитель языка |
| Внешний вид экранов (скриншоты) | Бренд и «как Telegram» (`19`, `21`) |
| Платный тариф, новые сервисы, любые расходы | Бюджет |
| Отклонение от решений в `docs/` | Решения принимает владелец |
| Всё, что отдаляет запуск 31.12 (`27`) | Решает владелец |

## Как Claude просит проверку

Одно короткое сообщение:

1. **Что проверить** (одной строкой).
2. **Где:** ссылка, скриншот или «откройте бот на телефоне».
3. **Что значит «всё хорошо»** (критерий).
4. **Варианты ответа:** «да», «нет, потому что…», правки.

Несколько проверок собираются в одно сообщение, чтобы не отвлекать
владельца по мелочам.

## Отчёт о выполненной задаче: скриншоты (решение владельца)

- **Каждую выполненную задачу Claude показывает скриншотами.**
- Mini App и лендинг: Playwright + Chromium, экран телефона (390 × 844),
  светлая тема, окружение Telegram подменено (mock). Каждый новый
  или изменённый экран, главные состояния: пусто, загрузка, ошибка, данные.
- CI и деплой: скриншот страницы GitHub Actions (репозиторий публичный)
  и ответа сервера.
- Боты: Claude не может снять экран чата Telegram. Показывает точные
  тексты сообщений и кнопок, владелец проверяет в Telegram сам.
- Скриншоты отправляются владельцу в чат, в репозиторий не коммитятся.
