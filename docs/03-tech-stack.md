# 03. Технологии: только Telegram + Cloudflare

> **Кратко:** Всё строим только на Telegram и Cloudflare, бесплатно. Узкое место: 100 000 запросов Workers в день. Резерв: $5 в месяц.

Цель: до ~10 000 пользователей не использовать других сервисов.

**Принцип (решение владельца): максимально использовать Cloudflare.**
Если задачу закрывает готовый сервис Cloudflare (бесплатно или очень дёшево),
берём его, а не пишем своё. Так быстрее успеваем к запуску (`27`).

## Кто что закрывает

| Задача | Сервис |
|---|---|
| Вход, номер телефона | Telegram (initData, `requestContact`) |
| Уведомления | Telegram Bot API |
| Живые платежи (после запуска, до 01.05.2027) | Решаем: Click или Payme (`10`, вопрос 29) |
| Mini App и лендинг | Cloudflare Pages |
| API и боты | Cloudflare Workers |
| База данных | Cloudflare D1 (SQLite) |
| Чат, сигнализация звонков | Cloudflare Durable Objects |
| Голосовые звонки | Cloudflare Realtime (SFU + TURN) |
| Фото | Cloudflare R2 |
| Домен и SSL | Cloudflare DNS |
| Очередь уведомлений и постов в каналы | Cloudflare Queues |
| Задачи по расписанию (напоминания, сгорание бонуса, отзывы) | Cron Triggers |
| Продуктовая аналитика и ошибки (`29`) | Workers Analytics Engine |
| Логи backend | Workers Logs (observability) |
| Аналитика лендинга | Cloudflare Web Analytics |

## Стек кода

- TypeScript, монорепозиторий.
- Hono (API и вебхуки ботов), Drizzle (ORM для D1), React + Vite (Mini App).
- Боты без grammY (G03): ответ идёт прямо в ответе на вебхук, без лишних запросов
  к Telegram и без `getMe` при холодном старте. Экономим лимит Workers.
  grammY берём, только если логика ботов станет сложной.

## Лимиты бесплатного тарифа (проверено: сентябрь 2026)

| Сервис | Лимит | Хватит на 10 000 пользователей? |
|---|---|---|
| Pages (статика) | без ограничений | да |
| Workers | 100 000 запросов/день | **узкое место** |
| Durable Objects | 100 000 запросов/день, 5 ГБ SQLite | да |
| D1 | 5 млн чтений, 100 000 записей/день | да |
| Realtime | 1 000 ГБ/мес (SFU + TURN вместе) | да, с большим запасом |
| R2 | ~10 ГБ | да, если сжимать фото |
| KV | ~1 000 записей/день | не использовать для частых записей |
| Queues | 10 000 операций/день, хранение 24 ч | да на старте; 1 сообщение ≈ 3 операции |
| Analytics Engine | 100 000 событий/день, 10 000 запросов/день | да, если не писать лишних событий |

## Правила экономии

- Статика: только через Pages.
- Кэш, без лишнего polling.
- Фото сжимать на клиенте (~200 КБ).
- Ресурс Cloudflare создаётся в той цели, где он впервые нужен (без «про запас»).
- Резервные копии базы: D1 Time Travel (восстановление на любую минуту).
  Срок: **7 дней на бесплатном тарифе**, 30 дней на Workers Paid (проверено 28.09.2026).
  Нужно дольше: экспорт D1 в R2 (решим до запуска).
- Проверять подпись initData на backend для каждого из трёх ботов.

## Резерв при росте

- Workers Paid: $5/мес. Архитектура не меняется. Поднимает лимиты
  Workers, Queues, Analytics Engine и других сервисов.
- Первыми, скорее всего, закончатся: запросы Workers и операции Queues.
- Перед запуском: перепроверить лимиты (они меняются).
