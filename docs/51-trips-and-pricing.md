# 51. Поездки, заявки, поиск, движок цен (как сделано)

> **Кратко:** Водитель публикует поездку по шагам, цена уже заполнена рекомендацией. Попутчик ищет поездку на день или оставляет заявку. Водитель смотрит заявки. Цена считается по формуле «км × ставка» или берётся из таблицы команды. Команда меняет формулу в админке, видит «было → стало», историю и откат. Сделано в G07 (29.09.2026).

## Движок цен (`apps/backend/src/modules/pricing`)

| Что | Как |
|---|---|
| Формула | `км × ставка`, округление до шага, затем пределы (`23`) |
| Стратегия | `pricing: 'per-km'` в `brands/<brand>/brand.config.ts` (`22`) |
| Порядок | цена места → цена региона → формула; ближняя пара главнее |
| Переменные | таблица `pricing_versions`, кэш в памяти Worker |
| Старт | ставка 300, шаг 5 000, от 30 000 до 600 000 сум (`16`) |
| Откат | новая версия со старыми значениями: история не теряется |
| Главные направления | `apps/backend/seed/main-directions.json`: Мирабад → центры регионов и Яккабаг |

- Рекомендация приходит вместе с пределами и шагом: человек меняет цену кнопками «Kamaytirish» и «Oshirish» на один шаг.
- Цена поездки записывается при публикации. Смена формулы **не меняет** опубликованные поездки.
- Цену вне пределов сервер не принимает (`errors.trips.price_out_of_bounds`).

## Поездка водителя (`modules/trips`)

Шаги: маршрут → день → время → места → цена → «В машине есть женщина» → комментарий → проверка → «Eʼlon qilish».

- Публикует только одобренный водитель (`50`). Места: от 1 до числа мест машины.
- Шаг «женщина» пропускается, если водитель женщина: отметка ставится сама (`06`).
- Время: не в прошлом и не дальше 30 дней. Живых поездок у водителя не больше 5.
- Маршрут и цена после публикации не меняются. Отменить можно.
- Статусы: `active`, `full`, `completed`, `cancelled` (`35`).
- `completed` ставит Cron каждые 15 минут: выезд + путь (60 км/ч) + 2 часа.
- **Точка встречи:** бот водителей пишет «Safar eʼlon qilindi». Водитель отвечает на это сообщение геолокацией, бот её сохраняет. Необязательно.

## Заявка попутчика (`modules/ride-requests`)

Шаги: маршрут → день → сколько человек (до 4) → цена → проверка.

- Открытых заявок у человека не больше 3.
- Заявка без времени, только день. `expired` ставит Cron после конца этого дня по Ташкенту.
- Предложение водителя по заявке: G08 (кнопка показывает «скоро»).

## Поиск

- День: «Bugun», «Ertaga», «Boshqa kun» (календарь). Время Ташкента (`35`).
- Поиск по региону находит поездки из всех его районов.
- Любой район Ташкента означает весь Ташкент: город один (`48`).
- Фильтр «Mashinada ayol bor»: переключатель над списком.
- Порядок: по времени выезда (рейтинга пока нет, `24`).
- Пусто: подсказка оставить заявку.

## Главные экраны: 3 действия

| Mini App | Действия |
|---|---|
| Водитель | Yangi safar · Yoʻlovchilar soʻrovlari · Mening safarlarim |
| Пассажир | Safar topish · Soʻrov qoldirish · Mening safarlarim (заявки) |
| Админ | Arizalar · Shikoyatlar · Boshqaruv |

- «Boshqaruv» открывает: Narxlar, Statistika (скоро). Так главный экран админа остаётся с 3 действиями.
- В списках короткие названия («Chilonzor → Samarqand shahri»), в карточке поездки полные.

## Админка цен (`packages/ui/src/pricing`)

1. Переменные формулы: ставка, шаг, минимум, максимум.
2. «Edi → boʻladi»: главные направления до и после, затем «Saqlash».
3. Таблица направлений: формула или цена команды. Нажать строку: своя цена или удалить её.
4. История версий: кто, когда, значения. «Shu versiyaga qaytish» возвращает версию.

Менять цены может только команда (`50`, роли).
