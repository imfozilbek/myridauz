# 211. G89: сочетания и гонки

> **Кратко:** оси, по которым аудит G89 искал опасные сочетания, опасные пары областей «поездка», «место», «деньги» с итогом G89 и все гонки «два человека в одну секунду» с защитой и тестом. Пары связи, команды и экранов: `212`; схемы статусов: `209`, `210`.

## Оси

| Ось | Значения |
|---|---|
| Роль | попутчик; водитель (заявка, одобрен, отказ); близкий без аккаунта; модератор; владелец |
| Состояние человека | новый (без регистрации), активный, без фото, заблокирован, заблокирован в пути, удалён |
| Статус объекта | поездка: живая, в пути, `completed`, `cancelled`; место: 6 статусов и отметки встречи; заявка, предложение, жалоба, фото (`209`, `210`) |
| Время | ночь 22:00…07:00 (бот без звука); до отъезда: срок ответа 24 ч, час до выезда, встреча за 30 мин; в пути; после конца: 24 ч чата, 7 дней оценки и жалобы; бонус 30 дней; полночь Ташкента |
| Лимиты и деньги | пустой кошелёк, остаток бонуса, бонус сгорел, 0 бонусов; одна живая поездка; одно место или заявка за раз; 5 близких; 3 звонка до брони; 60 запросов в минуту |
| Платформа | iOS (сокет свёрнутой Mini App живёт дольше), Android, Desktop, Web (близкий без Telegram) |
| Сеть | нет сети; потерянный ответ (сервер сохранил, экран не знает); повтор (второй телефон, Telegram шлёт webhook снова, очередь повторяет) |
| Кто ещё действует | вторая сторона, член команды, Cron, очередь |
