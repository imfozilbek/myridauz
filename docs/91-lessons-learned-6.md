# 91. Журнал уроков: продолжение 6

### №80. Тест нажимал кнопку за день до поездки

- **Что случилось:** «Mashinaga chiqdim» была видна за день до поездки (`89` P7). Три теста UI и e2e нажимали эту кнопку и проходили.
- **Причина:** часы тестов стоят на 1 октября, поездки в тестах на 2 октября. Ошибка продукта была обычным путём тестов, поэтому её никто не видел.
- **Следствие:** кнопки видны только в день поездки по Ташкенту. Тесты нажатия идут утром дня поездки (`TRIP_DAY`), подтверждённая бронь e2e уходит позже сегодня.
- **Урок:** для правила о времени тест проверяет обе стороны границы: «ещё рано» и «уже можно». Данные тестов не должны сами стоять на запретной стороне.

### №81. Находка обхода была уже исправлена

- **Что случилось:** F-P5 (`90`) сказал, что последние места вне зоны уводят карту за границу. Фильтр зоны уже был с G26, но теста на него не было.
- **Причина:** агент обхода читал `recent-list.tsx` без `point-screen.tsx`, где фильтр стоит.
- **Следствие:** код не меняли, добавили тест. Он падает, если фильтр убрать.
- **Урок:** находку обхода сначала проверить по коду. Уже исправленное закрыть тестом, а не второй правкой.

### №82. LIMIT в базе, фильтр после

- **Что случилось:** медиана цен (`90` F-A7) брала 5000 самых старых поездок с даты, потом выбрасывала будущие и отменённые. Список команды (F-A6) так же резал на 200 без слова.
- **Причина:** общий метод `since(from, limit)` отдавал всё подряд, отбор шёл в коде после `LIMIT`.
- **Следствие:** два метода с отбором в SQL: `between` (день команды) и `pricedBetween` (прошлые, не отменённые, свежие первыми), новый индекс `trips_depart`. Мок e2e тоже отдаёт поездки по дню запроса.
- **Урок:** всё, что сужает список, стоит в запросе до `LIMIT`. Лимит только страхует, а не решает, что увидит человек.

### №83. Тест стенда открывал «первую карточку» водителя

- **Что случилось:** после F-D3 сценарий G21 №2 упал: водитель отменил бронь, а экран попутчицы не изменился.
- **Причина:** тест открывал первую карточку с именем водителя. Новый порядок поднял наверх другую бронь Зарины, уже в дороге, из другого сценария. Тест смотрел не на ту бронь.
- **Следствие:** тест открывает нужную бронь по её ссылке (`BOOKING_LINK`), как кнопка бота.
- **Урок:** тест выбирает запись по её id или ссылке, а не по месту в списке. Порядок списка может меняться по делу.

### №84. Имя бренда в тексте продукта

- **Что случилось:** в согласованном тексте P2 стояло «Rida». `check:text` остановил коммит: имя бренда вне `brands/`.
