# 20. Бренд: цвета и продуктовый язык

> **Кратко:** Цвета: белый, бирюзовый, янтарный. Только светлая тема. Слоган «Manzil sari».

Интерфейс простой (`19-design-system-and-ux.md`), но **узнаваемый**:
человек сразу видит, что это Rida.

## Цвета (решение владельца)

Три цвета бренда: **белый, бирюзовый, янтарный.**

| Токен | HEX | Где используется |
|---|---|---|
| `color.bg` | `#FFFFFF` | Фон всех экранов |
| `color.brand` | `#14B8A6` | Бирюзовый бренда: логотип, иконки, крупные поверхности, выделение |
| `color.brand.strong` | `#0D9488` | Главные кнопки (белый жирный текст ≥ 17px) |
| `color.brand.text` | `#0F766E` | Бирюзовый текст и ссылки на белом |
| `color.brand.soft` | `#F0FDFA` | Мягкий фон карточек и выбранных элементов |
| `color.accent` | `#F59E0B` | Янтарный акцент: бейджи, бонус, важные отметки (тёмный текст) |
| `color.accent.text` | `#B45309` | Янтарный текст на белом |
| `color.text` | `#1F2937` | Основной текст |
| `color.text.muted` | `#6B7280` | Второстепенный текст |
| `color.danger` | `#DC2626` | Ошибки, отмена, блокировка |

### Контраст (WCAG: стандарт читаемости)

| Пара | Контраст | Правило |
|---|---|---|
| Текст `#1F2937` на белом | 14.7 | Отлично |
| Белый текст на `#0D9488` | 3.7 | Только крупный жирный текст (кнопки) |
| Текст `#0F766E` на белом | 5.5 | Можно для обычного текста |
| Тёмный текст на `#F59E0B` | 6.8 | Отлично; белый текст на янтарном: **нельзя** (2.2) |
| Бирюзовый `#14B8A6` на белом | 2.5 | **Не для текста**, только иконки и фон |

- HEX-значения живут **только** в `brands/<brand>/theme.ts`. `packages/ui`
  и приложения используют только имена токенов (`22`).

## Только светлая тема (решено)

- **Тёмной темы не будет никогда.**
- Тема Telegram пользователя **игнорируется**.
- TelegramUI: `AppRoot appearance="light"`.
- Через SDK задаём белые цвета шапки, фона и нижней панели Telegram
  (`setHeaderColor`, `setBackgroundColor`, `setBottomBarColor`).

## Продуктовый язык (голос Rida)

- **Дружелюбно и уважительно**: обращение на «Siz».
- **Коротко**: одна мысль в одной фразе.
- **Спокойно и надёжно**: без восклицательных знаков и давления.
- **Про поездку вместе, не про такси**: «birga», «safar», «yoʻlovchi»
  (глоссарий `25`). «Hamroh» только в маркетинге (лендинг, каналы).
- Одни и те же слова для одних и тех же вещей во всех ботах и Mini App
  (словарь терминов: в `packages/i18n`).

## Слоган (решено владельцем)

**«Manzil sari»**: «К цели» / «Навстречу месту назначения».

- Хранится в конфиге бренда (`brands/rida/`, `22-multi-brand.md`), не в коде.
- Где показываем: экран приветствия Mini App, описание ботов,
  описание каналов, лендинг.

## Узнаваемость

- Бирюзовый цвет: в шапке и главных кнопках всех трёх Mini App.
- Единый логотип и аватар для всех ботов и каналов. Нужен **до G03**
  (экран загрузки, аватары ботов). Предложено: Claude делает простой
  текстовый логотип «Rida» в цветах бренда, владелец утверждает
  (`10` вопрос 35).
- Посты в каналах: единый шаблон с фирменными эмодзи-метками.
