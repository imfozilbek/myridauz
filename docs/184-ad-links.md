# 184. Ссылки для рекламы: ссылка с меткой (G83)

> **Кратко:** просьба владельца 14.10.2026. Когда покупаем рекламу, команда за минуту получает ссылку с меткой источника (G55, `116`) и отдаёт её продавцу рекламы вместе со своим контентом. Ссылка ведёт в бот или в наш канал, на выбор (решение владельца 14.10.2026). Готового поста нет: только ссылка (решение владельца 14.10.2026). «Statistika» показывает, что дала каждая реклама: сколько нажали, сколько записались, во сколько обошёлся один записавшийся. Админка → «Boshqaruv» → «Reklama havolalari». Макет утверждён 14.10.2026: `goals/g83/approved/7-team-ad-links.png`. Около 4,5 ч.

## Ссылка в бот

- Ведёт в бот: `t.me/<бот>?start=ad-<код>`. Бот, а не сразу Mini App: после Start бот может написать человеку об открытии направления, а человек видит приветствие с видео (`181`).
- Уход между ботом и Mini App видно в воронке «Roʻyxatga yozilish» (`183`). Если он большой, попробуем прямую ссылку на Mini App.
- Код: `ad-` и 6 случайных латинских букв и цифр, по правилу `116` (до 21 знака). Имени рекламы в ссылке нет: продавец не видит наших пометок.
- Бот запоминает метку при Start как первое касание (`116`). Кнопка приветствия передаёт её в Mini App, запись списка хранит её в `via` (`181`).
- Имя бота берётся из настроек среды (`brands/rida/environments.ts`), не из кода (`22`).

## Ссылка в канал

- Своя пригласительная ссылка на каждую рекламу: бот каналов создаёт её в Telegram (`createChatInviteLink`, имя ссылки: имя рекламы). Бот каналов уже администратор каналов (G80, `176`).
- Кто вступил по этой ссылке, Telegram сообщает в `chat_member` (поле `invite_link`); G80 эти события уже принимает. Выход из канала приходит так же.
- «Roʻyxatga yozildi»: вступившие по ссылке, которые потом записались в список (тот же Telegram id).
- Каналы: во внутренней среде «MyRida | Oʻzbekiston» и «MyRida | Viloyatlar»; в проде `@rida1uz` и 67 каналов направлений: сначала область, потом канал (`176`). Список каналов из настроек среды, не из кода (`22`).
- Обычная ссылка `@имя` канала не считается: только своя пригласительная.

## Условия рекламы

Как каналы продают рекламу (решение владельца 14.10.2026). Всё выбором, печатать не нужно.

| Поле | Варианты | Что значит |
|---|---|---|
| Narxi | число в сумах, по желанию | сколько заплатили за всё |
| Necha kun turadi | 1, 2, 3, 7 kun, Doimiy | сколько дней пост висит в канале; «Doimiy»: без удаления |
| Tepada | Yoʻq, 1, 2, 3 soat | сколько часов после нашего поста в канале нет других постов |
| Qadalgan (pin) | Yoʻq, 12, 24, 48 soat | сколько часов пост закреплён |

- Условия видны в списке и на экране ссылки. Когда наберутся данные, «Statistika» сравнит их: окупается ли закреп и «топ», сколько дней нужно посту.

## Данные

| Таблица `ad_links` | Что |
|---|---|
| `code` | `ad-k7f2qx`: метка в ссылке |
| `target`, `channel_id`, `invite_link` | куда ведёт: `bot` или `channel`; какой канал; пригласительная ссылка канала |
| `place` | где реклама (`telegram`, `instagram`, `blogger`, `other`) |
| `name`, `price` | имя для статистики; цена в сумах, по желанию |
| `days`, `top_hours`, `pin_hours` | условия: дни в канале (пусто: без удаления), часы в «топе», часы в закрепе |
| `created_by`, `created_at` | кто и когда создал |

- «Bosdi»: Start бота с этой меткой. «Ilovani ochdi»: первый экран опроса с этой меткой. «Roʻyxatda»: записи списка с этой меткой.
- «Doʻst orqali»: записи по приглашению людей, которые сами пришли по этой ссылке (метка друга, `116`).
- Цена одного: цена, делённая на «Roʻyxatda». Нет цены: поле пустое.
- Видит только команда. Номера продавцов и имена людей не храним.
