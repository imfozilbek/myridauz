# 184. Ссылки для рекламы: ссылка с меткой и готовый пост (G83)

> **Кратко:** просьба владельца 14.10.2026. Когда покупаем рекламу, команда за минуту получает ссылку с меткой источника (G55, `116`) и готовый пост и отправляет их продавцу рекламы. «Statistika» показывает, что дала каждая реклама: сколько нажали, сколько записались, во сколько обошёлся один записавшийся. Админка → «Boshqaruv» → «Reklama havolalari». Макет: `goals/g83/7-ad-links`. Около 3,5 ч.

## Путь команды

| № | Экран | Что там |
|---|---|---|
| 1 | Reklama havolalari | «Yangi havola» и список ссылок: где, когда, для кого; нажали, записались; цена одного записавшегося |
| 2 | Yangi havola | Выбрать, где реклама (Telegram kanal, Instagram, Bloger, Boshqa) и для кого (yoʻlovchilar, haydovchilar). Ввести имя (видно в статистике) и цену, если хотим считать деньги |
| 3 | Havola tayyor | Ссылка с кнопкой «Nusxa». Готовый пост: картинка, текст, кнопка со ссылкой. «Postni yuborish» открывает окно Telegram «отправить в чат»; «Matn va havolani nusxalash» |
| 4 | Одна ссылка | Bosdi → Ilovani ochdi → Roʻyxatda с уходом на шаге; цена и цена одного; сколько записалось по приглашениям этих людей; сколько вступили в канал |
| 5 | У продавца | Пост с кнопкой «🚀 Roʻyxatga yozilish»: можно переслать или скопировать в свой канал |

## Ссылка

- Ведёт в бот: `t.me/<бот>?start=ad-<код>`. Бот, а не сразу Mini App: после Start бот может написать человеку об открытии направления, а человек видит приветствие с видео (`181`).
- Уход между ботом и Mini App видно в воронке «Roʻyxatga yozilish» (`183`). Если он большой, попробуем прямую ссылку на Mini App.
- Код: `ad-` и 6 случайных латинских букв и цифр, по правилу `116` (до 21 знака). Имени рекламы в ссылке нет: продавец не видит наших пометок.
- Бот запоминает метку при Start как первое касание (`116`). Кнопка приветствия передаёт её в Mini App, запись списка хранит её в `via` (`181`).
- Имя бота берётся из настроек среды (`brands/rida/environments.ts`), не из кода (`22`).

## Готовый пост

- Текст: «Описание до Start» из `182`; для водителей боли водителя. Правила рекламы: без «taksi», без «tekshirilgan haydovchi», без цен и бонусов, без сравнения с конкурентами.
- Картинка: та же, что в описании бота. Кнопка «🚀 Roʻyxatga yozilish» с этой ссылкой.
- Отправка: готовое сообщение Telegram и окно «отправить в чат», как в «Поделиться поездкой» (`43`: `prepared-card.ts`, `share-card.ts`). Новое: фото вместо простой карточки.

## Данные

| Таблица `ad_links` | Что |
|---|---|
| `code` | `ad-k7f2qx`: метка в ссылке |
| `place`, `role` | где реклама (`telegram`, `instagram`, `blogger`, `other`); для кого |
| `name`, `price` | имя для статистики; цена в сумах, по желанию |
| `created_by`, `created_at` | кто и когда создал |

- «Bosdi»: Start бота с этой меткой. «Ilovani ochdi»: первый экран опроса с этой меткой. «Roʻyxatda»: записи списка с этой меткой.
- «Doʻst orqali»: записи по приглашению людей, которые сами пришли по этой ссылке (метка друга, `116`).
- Цена одного: цена, делённая на «Roʻyxatda». Нет цены: поле пустое.
- Видит только команда. Номера продавцов и имена людей не храним.
