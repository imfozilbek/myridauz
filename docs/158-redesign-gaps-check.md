## В G75: правила и поведение

**А. Плохой исход**
- Карточка брони на главном просто исчезает при отказе, сроке, отмене; об исходе говорит только бот (`home/home-items.ts:7`).
- «Bekor qilindi» одной брони звучит как отмена всей поездки (`bookings.json:113`).
- После «Yoʻlga chiqdim» видна ссылка «Joyni bekor qilish», касание даёт общую ошибку (`bookings/passenger-booking.tsx:97`).
- Лимит 3 запросов виден только после «Soʻrov yuborish», на «Safar» его нет.
- «Последнее место заняли»: только текст, нет шага «Oʻxshash safarlar» (`bookings/book-points.tsx:51`).
- Общей плашки состояния нет (у брони, «Safar» и заявки разные), шага «Soʻrov qoldirish» нет, у заявки нет причины.

**В. Конец поездки**
- Нет пути «не могу ехать» после выезда (`bookings/domain/booking.ts:103`).

**Г. Деньги водителя**
- Шторка «Yangi soʻrov» всегда показывает «Tasdiqlash», кошелёк не проверяет (`action-sheet/kinds/request-items.tsx:71`).
- Бот: отказ только всплывающим текстом, без суммы и кнопки пополнения.
- Показана вся комиссия, а не сумма нехватки (`wallet.json:40`).
- «Hisobni toʻldirish» открывает поддержку без готового текста (`account/support-button.tsx:12`).
- В шторке «Butun salon» нет комиссии (`requests/salon-sheet.tsx:64`).
- Три бонуса в «Hamyon» называются одинаково «Boshlash bonusi».

**Д. Точки и ссылки**

**Е. Списки**

**Ё. Профиль**

**Ж. Регистрация и блок**
