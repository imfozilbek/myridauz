# 94. Физика навигации: «Назад», прокрутка, закрытие

> **Кратко:** обход 02.10.2026 трёх Mini App по коду. Как работают «Назад», прокрутка, закрытие приложения и окон. 37 находок, 11 главных. Корень был один: каждый экран решал сам (урок №66). Все закрыты в G33 (`goals/G33-navigation-physics.md`): общие правила теперь в обёртках `packages/ui`.

## Остальные находки

### «Назад»

| № | Находка |
|---|---|
| B1 | `BackButton` прячется и показывается заново при каждой перерисовке (стрелочные функции). Нужна «последняя функция» через ref, как у `MainButton` |
| B2 | Нет стека владельцев: если два `BackButton` окажутся вместе, один тап сработает дважды, а уход дочернего спрячет кнопку родителя. Сейчас таких мест нет, риск на будущее |
| B3 | Пустой экран без «Назад» в обратной поездке, пока грузится рекомендация (`new-trip-flow.tsx`) |
| B4 | Исправление отклонённой заявки водителя: нет «Назад» к экрану статуса |
| B5 | Заявка водителя: смена марки и «Назад» на шаге модели оставляет старую модель |
| B6 | Поиск на экране точки: «Назад» закрывает весь экран, а не очищает поиск |
| B7 | Согласие при регистрации без «Назад»; шаг пола не показывает прошлый выбор |
| B8 | Карта из подтверждённой брони: «Назад» ведёт к поездке, а не к брони |
| B9 | Админка: одобрение теряет исправленный номер при «Назад» и при ошибке |
| B10 | Ссылки из бота `trip`, `find`, `subscribe` могут открыться повторно после перезапуска шлюза аккаунта |
| B11 | Профиль, открытый с «Sozlamalar», возвращает на главный экран, а не туда, где был человек |

### Прокрутка

| № | Находка |
|---|---|
| S1 | Шаги одного вида без `key` (места → способ в брони, шаги заявки попутчика): React берёт старый экран, прокрутка и введённый текст переходят на новый шаг |
| S2 | Везде `100vh`, а не стабильная высота Telegram (`--tg-viewport-stable-height`). На Android при клавиатуре высота прыгает, короткие экраны чуть прокручиваются |
| S3 | Тихое обновление (лента, возврат в приложение) меняет длину списка под пальцем: в очереди админки можно нажать не ту заявку |
| S4 | Статистика: смена периода схлопывает страницу в скелетон, переключатель прыгает под пальцем |
| S5 | Поле ввода чата берёт `env(safe-area-inset-bottom)`, а не переменные Telegram |
| S6 | Список найденного на карте (`max-height: 40vh`) уходит под клавиатуру; под картой на весь экран прокручивается старая страница |
| S7 | Фото заявки в админке заменяет экран заявки: при возврате история и журнал грузятся заново |

### Свайп вниз (W1)

- Сейчас выключен везде. В Telegram свайп вниз сворачивает приложение: это родное поведение.
- Нужен выключенным только там, где палец двигает что-то: карта, камера, форма с введённым текстом, чат.
- На списках и просмотре (главный, результаты, мои поездки, очереди, история, кошелёк, документы) его надо включить.
