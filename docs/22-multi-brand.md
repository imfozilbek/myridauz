# 22. Несколько брендов на одном коде (white-label)

> **Кратко:** Код white-label: второй бренд запускается из папки `brands/<brand>/` на отдельном аккаунте Cloudflare, без изменения кода.

## Цель (решение владельца)

- Сейчас запускаем **Rida** (`myrida.uz`) с моделью A (комиссия).
- Позже рядом можно быстро запустить **второй продукт** на том же коде:
  другое имя, домен, цвета, боты, **отдельный аккаунт Cloudflare**,
  модель B (подписка).
- Два продукта конкурируют на рынке. Код: один.

## Главное правило для кода

- **Имя «Rida» и любые данные бренда не пишутся в коде.**
  Всё, что отличает бренды,: в **конфигурации бренда**.
- Внутренние имена пакетов: нейтральные: `@platform/ui`, `@platform/i18n`
  и т.д. (не `@rida/...`).

## Что входит в конфигурацию бренда

| Что | Пример для Rida |
|---|---|
| Название, слоган | Rida, слоган (`20-brand.md`) |
| Домен | `myrida.uz` |
| Цвета (токены темы) | Белый, бирюзовый, янтарный |
| Логотип, иконки ботов | Файлы бренда |
| Боты (3 шт.), каналы | `@myrida_bot`, `@myrida_haydovchi_bot`, `@myrida_admin_bot`; ID каналов. Токены только в секретах Cloudflare (`32`) |
| Модель монетизации | `commission` (A) или `subscription` (B) (`12-monetization.md`) |
| Параметры монетизации | 10%, мин. 3 000; акция 3 × 500 000 / или цена подписки |
| Параметры цен | Ставка 300 сум/км, пределы 30 000…600 000 (`16`) |
| Языки | `enabled_locales` (`13-i18n.md`) |

- Тексты с именем бренда: через переменную: `{brand}` в переводах.
- Цвета: только `brands/<brand>/theme.ts`, `packages/ui` читает его.
- Параметры цен и денег в конфиге: **стартовые значения**. Текущие
  значения живут в базе и меняются в админке (`23`, `12`).

## Структура в репозитории

```
brands/
  rida/
    brand.config.ts     имя, домен, модель, параметры
    theme.ts            цвета
    assets/             логотип, иконки
    wrangler.toml       настройки Cloudflare этого бренда
  <второй-бренд>/       та же структура
```

## Изоляция брендов

- **Полная:** отдельный аккаунт Cloudflare, отдельные база D1, R2,
  Durable Objects, отдельные боты и домен.
- Пользователи и данные брендов **никогда не смешиваются**.
- Секреты (токены ботов, ключи): у каждого бренда свои, в своём аккаунте.
- Репозиторий публичный (решение владельца), поэтому общий код брендов
  виден. Изолированы данные и секреты, а не код.

## Деплой

- Одна команда на бренд: `deploy --brand=rida`.
- CI собирает и выкладывает каждый бренд отдельно, в свой аккаунт.
- Новый бренд = новая папка в `brands/` + новый аккаунт Cloudflare
  + 3 новых бота. **Код не меняется.**

## Что это значит для текущей работы

- Модуль `billing`: стратегия; сейчас только `commission`, подписка появится,
  когда понадобится (`12`, правило «без кода на будущее»).
- Никакого текста, цвета, домена или имени бота «зашитого» в код.
- Проверка в CI: поиск слова «Rida» и HEX-цветов вне `brands/`: ошибка.
