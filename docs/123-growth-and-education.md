# 123. Рост и обучение: петли, инструкции, подсказки

> **Кратко:** план владельца и Claude 06.10.2026, после целей G58 … G68 (экраны готовы). Три части: 1) **петли роста** внутри продукта; 2) **инструкции**: короткие видео и посты по каждому пути человека для Instagram, каналов и ботов; 3) **подсказки по шагу**: человек остановился на шаге, бот присылает видео именно этого шага. Видео делает генератор из стенда, поэтому они всегда как настоящее приложение. Цели G69, G70.

### Карточки «Men Rida bilan» (решение владельца, G69)

Человек сам рассказывает о Rida: история Telegram (`shareToStory`) или готовое сообщение в любой чат (`shareMessage`). Макет: `goals/g69/1-share-cards.png`.

| Кто | Момент | Карточка | Ссылка ведёт |
|---|---|---|---|
| Попутчик | регистрация | «Madina Rida bilan yoʻlga chiqadi» | регистрация (`via=share-join`) |
| Попутчик | первая поездка, 5, 10, 25 | «Toshkentdan Urgutga 4 kishi boʻlib bordik», «Yoʻl xarajati 4 ga boʻlindi» | поиск этого направления |
| Водитель | заявка одобрена | «Dilnoza: tekshirilgan Rida haydovchisi» | его поездки |
| Водитель | 10, 50, 100 попутчиков; рейтинг 4,9 | «Jasur 100 yoʻlovchini manziliga yetkazdi» | его поездки |

- Экран праздника после момента: карточка, «Hikoyaga joylash», «Chatga yuborish», «Keyinroq»; не обязательно; в живой карточке бота кнопка «Ulashish».
- Только имя и фото по желанию; нет номера, адреса, Telegram ID; районы прошлой поездки можно.
- Суммы экономии не пишем: нет честной базы для сравнения (урок №9); пишем «xarajat N ga boʻlindi».
- Не «daromad» (заработок) у водителя: «yoʻl xarajati qoplandi» (урок №2).
- Ссылка с меткой `via=share-<момент>` и публичным id автора: видно, кто кого привёл (`116`).
- Картинка карточки: генератор (рисунок направления, цвет роли), хранение 1 день как истории (`117`).

### Почему хочется нажать (G69)

Макеты: `goals/g69/2-share-motivation.png`, `3-share-voice.png`. Семь правил для каждой кнопки «ulashish»:

| Правило | Как |
|---|---|
| Выгода человеку | попутчику: польза друзьям («Doʻstlaringiz ham shunday borsin»); водителю: свободные места заполнятся |
| Видно заранее | блок «Doʻstlaringiz shuni koʻradi»: та же карточка, что увидит друг |
| Кнопка называет адресата | «Urgutga boradigan doʻstimga», «Guruhimga yuborish», а не «Ulashish» |
| Лучший момент | сразу после «Yetib keldingiz», одобрения, круглого числа |
| Видно, что вышло | в профиле «Sizning taʼsiringiz»: кто пришёл по ссылке; знаки «Yoʻl hamrohi» (1), «Rida elchisi» (5), «Yoʻnalish qahramoni» (25) |
| Своим голосом (решение владельца) | карточка от первого лица: «Men tekshirilgan Rida haydovchisiman», «Urgutga 4 kishi boʻlib bordik!»; человек выбирает одну из 3 готовых фраз; похвала «eng faol 10 tadan biri» только если так в данных (урок №9) |
| Без давления | «Keyinroq» всегда есть; один момент: одно предложение; без наград деньгами до решения владельца |

- Без эмодзи и смайликов (решение владельца 06.10: «это не серьёзно»): только в историях (сторис): там только текст. Во всех остальных местах (экраны, посты в чатах, боты, каналы) всё как есть.
- Меряем: `share_shown` и `share_done` по каждой кнопке и моменту (`29`); тексты кнопок проверяем A/B.

## 2. Инструкции (G70)

Одна инструкция = один шаг пути (пути `118`). Из неё 3 вида:

| Вид | Где | Формат |
|---|---|---|
| Короткое видео | Instagram Reels, каналы, бот | 9:16, 15 … 30 секунд, экран телефона, крупные подписи, музыка с лицензией (`41`) |
| Карусель | Instagram | 5 … 7 картинок: шаг за шагом |
| Видео в боте | бот попутчика или водителя | то же видео, короткая подпись, кнопка на нужный экран |
| Приветствие | первое сообщение бота | P1 (попутчик) или D1 (водитель) сразу в приветствии (`122`); P1 и D1 делаем первыми |

**Попутчик:**

| № | Инструкция |
|---|---|
| P1 | Roʻyxatdan oʻtish: 2 ekran |
| P2 | Safar topish: Qayerdan, Qayerga, kun |
| P3 | Joy band qilish: qayerdan olib ketadi, qayerga |
| P4 | Haydovchi bilan chat va qoʻngʻiroq |
| P5 | Yaqinlarimga yuborish: safarni kuzatish |
| P6 | Safar kuni: «Mashinaga chiqdim», «Yetib keldim» |
| P7 | Soʻrov qoldirish va takliflar |
| P8 | Butun salon |
| P9 | Xabar bering va kanallar |
| P10 | Baholash va qaytish safari |

**Водитель:**

| № | Инструкция |
|---|---|
| D1 | Haydovchi boʻlish: 2 ekran, 3 rasm |
| D2 | Safar eʼlon qilish: bir ekran |
| D3 | Soʻrovga javob: botdan «Qabul» |
| D4 | Yoʻlovchilar soʻrovlariga taklif |
| D5 | Safar kuni: yoʻl tartibi, navigator |
| D6 | Hamyon va komissiya |
| D7 | Oʻz yoʻlovchilarini olib kelish: havola, QR, story |

**Как делаем:** генератор в `brand-kit` берёт сценарий стенда (`75`), снимает экран (Playwright) в рамке телефона, ставит подписи из файла языка и музыку. Получаются mp4 и PNG. После каждой цели, которая меняет экран, видео собирается заново (урок №10). Тексты подписей: согласие владельца и проверка носителем (`25`).

## 3. Подсказки по шагу (G70)

Шаги берём из воронок аналитики (`29`). Остановился на шаге: одна подсказка с видео этого шага и кнопкой на нужный экран.

| Кто | Где остановился | Когда | Подсказка |
|---|---|---|---|
| Попутчик | Открыл бот, не зарегистрировался | через 24 ч | P1 |
| | Зарегистрировался, не искал | через 24 ч | P2 |
| | Искал, поездок не было | через 2 ч | P7, P9 |
| | Нашёл поездку, не забронировал | через 3 ч | P3 |
| | Первая поездка была, второй нет 14 дней | день 14 | P10, P7 |
| | Заявка без предложений | через 6 ч | петля 2 |
| | Нет активности 30 дней | день 30 | доска дня своего направления |
| Водитель | Начал заявку, не отправил | через 24 ч | D1 |
| | Одобрен, не публиковал 48 ч | через 48 ч | D2 |
| | Опубликовал, нет брони | за 12 ч до выезда | D7 |
| | Запрос истёк без ответа | сразу после | D3 |
| | Нет поездок 21 день | день 21 | D4 |

**Правила подсказок** (как `122`):
- Не больше 1 подсказки в неделю на человека и не больше 2 на один шаг; сделал шаг: подсказки этого шага прекращаются.
- Без звука, только 10:00 … 20:00, никогда во время поездки.
- Кнопка «Kerak emas» выключает подсказки (не служебные сообщения).
- Метка `via=tip-<шаг>`; считаем, сделал ли человек шаг за 72 ч.

**Каналы:** раз в неделю пост «Qanday ishlaydi» по очереди из инструкций; закреплённый «Qoʻllanma» со ссылками на все видео.
