# 53. Чат, уведомления, «Поделиться поездкой» (как сделано)

> **Кратко:** У каждой брони свой чат внутри Mini App: сообщения приходят сразу, контакты скрываются. Если человек не в чате, его бот пишет «Yangi xabar». Все сообщения ботов идут через очередь. Попутчик одной кнопкой отправляет близким карточку поездки; близкие видят поездку без регистрации и получают «mashinaga chiqdi» и «yetib keldi». Сделано в G09 (29.09.2026).

## Чат (`07`)

| Что | Как сделано |
|---|---|
| Где живёт | один Durable Object `ChatRoom` (SQLite) на одну бронь, WebSocket Hibernation |
| Ключ чата | `b` + id брони; `o` + id предложения водителя; `t` + id разговора по заявке до брони (G64, `146`). Бронь из предложения продолжает его чат |
| Кто входит | только попутчик и водитель этой брони. Команда читает чат только по жалобе (G11) |
| Вход | API с подписью Telegram даёт билет на 1 минуту, сокет открывается по билету. В билете только свой id: собеседника сервер находит сам (`65` A3) |
| Заблокированный | билет не получает (`blockedGuard`) |
| Что пишут | только текст, до 1000 знаков. Голоса нет |
| Системные строки | «Joy soʻraldi», «Haydovchi taklif yubordi», «Joy tasdiqlandi», «Rad etildi», «Bekor qilindi» |
| История | последние 100 сообщений, чат остаётся после поездки |

## Маскировка (`07`)

- Телефон в любом виде: цифры, пробелы, дефисы, скобки, `+998`, цифры словами (узбекский латиница и кириллица, русский), смесь цифр и слов → «***».
- `@username`, почта, `t.me`, `wa.me`, Instagram, Facebook, VK, TikTok и любые ссылки → «***».
- Суммы («1 500 000 soʻm»), даты («02.10.2026», «2026-10-02»), время («08:30») не трогаются.
- Отправитель видит предупреждение. Каждая третья попытка одного человека: сообщение команде в админ-бот.
- Код: `apps/backend/src/modules/chat/domain/mask.ts`, тесты: 36 видов контактов и 13 обычных фраз.

## Уведомления и очередь (`03`)

- Очередь `rida-notifications`: все сообщения ботов о бронях, чате и поездке идут через неё.
- Попутчику пишет бот попутчиков, водителю бот водителей, команде админ-бот.
- «Yangi xabar» с кнопкой «Chatni ochish», только если человек не в чате, и не чаще раза в 5 минут на чат.
- Каждое сообщение тому, кого нет в чате, прибавляет 1 к «1 xabar» на его главном экране; открытие чата сбрасывает счётчик (G53, `114`).
- Telegram просит подождать (429): сообщение ждёт в очереди. Бот заблокирован (403): сообщение отбрасывается, Rida работает дальше.

## «Yaqinlarimga yuborish» (`43`)

1. Бронь подтверждена → в брони кнопки «Yaqinlarimga yuborish», «Mashinaga chiqdim», «Yetib keldim», «Ulashishni toʻxtatish».
2. Карточка уходит через родное окно Telegram (`savePreparedInlineMessage` + `shareMessage`), запасной путь: `t.me/share/url`.
3. Кнопка карточки: `t.me/<бот попутчиков>?start=follow_<токен>`. Бот отвечает кнопкой, которая открывает Mini App в режиме «только смотреть». Так работает без настройки BotFather.
4. Близкий видит: имя попутчика, маршрут, время, имя водителя, машину, госномер, место посадки попутчика на карте (пятак или его точка, `111` Q1), статус. Телефонов и переписки не видит.
5. «Xabar olish»: бот пишет близкому о посадке, прибытии и отмене. Не больше 5 близких на бронь.
6. «Men ham yoʻlga chiqaman» внизу экрана близкого: Mini App переходит к обычной регистрации попутчика (`18`).
7. Ссылка закрывается кнопкой «Ulashishni toʻxtatish» и сама через 24 часа после расчётного прибытия. В базе хранится только хэш токена.

## G60: чат и близкие заново

- Шапка чата: фото, машина, номер, круглая кнопка звонка; строка поездки открывает бронь; готовые ответы; серая строка про скрытые номера (макет g60/2).
- Чат и звонок живут 24 часа после прибытия (`AFTER_TRIP_TALK_HOURS`); потом чат только для чтения, плашка «Suhbat yopildi» (`129`).
- Экран близких: крупно состояние, время приезда до прибытия, 3 шага, водитель с номером, места на карте; «Vaqt oʻzgardi» при сдвиге (`124` И).

## G64: разговор по заявке до брони

- Один чат на пару «заявка + водитель» (`request_talks`): сообщения, звонки, предложения этого водителя и бронь из них.
- Сверху строка заявки, над полем действие водителя или карточка предложения; готовых ответов нет до брони (макеты g64/4, g64/5).
