# G19. Живое обновление всех экранов (realtime)

> **Кратко:** Экраны Mini App обновляются сами, когда действует другой человек: бронь, подтверждение, отмена, заявка, модерация, кошелёк. Сейчас данные грузятся только при открытии экрана (проблема владельца 30.09.2026). Цель охватывает все 3 Mini App и все экраны с чужими изменениями.

```text

docs/61-capacity.md, docs/21-native-feel.md, docs/31-testing-and-quality-gates.md,
docs/32-ci-security.md.

Сделать:
1. Аудит: таблица «экран → чьи действия его меняют → тема сигнала»
   для всех экранов 3 Mini App (пассажир, водитель, админ). Ни одного
   экрана с чужими данными вне таблицы.
```
