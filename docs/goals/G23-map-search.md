# G23. Поиск места по названию на карте

> **Кратко:** на экране карты (G22) попутчик находит махаллю, улицу или ориентир по названию, по-узбекски или по-русски. Названия из той же карты OSM, индекс в D1. Решение владельца 30.09.2026.

```
ЦЕЛЬ G23: Поиск места по названию на карте
Ветка: goal/g23-map-search от свежего main (docs/34).

Сделать:
1. Данные поиска: названия из файла карты, индекс в D1 (FTS).
2. Кириллица и латиница: «Чиланзар» и «Chilonzor» находят одно место.
3. API: GET /map/search?q=... отдаёт до 10 мест, debounce, кэш на краю.
4. Экран карты: поле поиска сверху, список, нажатие ведёт карту к месту.
5. Сначала места рядом с городом отправления поездки.
6. Новые тексты по docs/25, одним файлом на согласие владельца.
7. Тесты: unit, API, e2e, скриншоты.
8. Нагрузка на D1 и Worker: расчёт в docs/61.
9. docs: 67, 14, 61, INDEX, уроки, INDEX целей.

Проверка владельцем:
1. Найти махаллю латиницей и кириллицей: карта переезжает к месту.
2. Найти ориентир и сохранить точку: водитель видит её и получает сообщение.
```
