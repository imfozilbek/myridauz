# G33. Физика навигации: «Назад», прокрутка, закрытие

> **Кратко:** три Mini App ведут себя как сам Telegram. Находки: `../94`. Правила в обёртках `packages/ui` (урок №66). Ветка `goal/g33-navigation-physics`. Запуск не отдаляет.

## Definition of Done

### Решения и тексты

- [ ] Владелец решил одним сообщением: черновик 24 часа, свайп вниз на списках, «Sozlamalar» только на главном, «Yopish» после отзыва и жалобы (совет: да на всё).
- [ ] Тексты согласованы (список ниже).

### «Назад»

- [ ] «Назад» есть на каждом экране, кроме главного (F9, B3, B4, B7).
- [ ] Один тап: один шаг; кнопка не мигает (B1, B2).
- [ ] Шаг пути возвращается с прежним ответом: маршрут, точки, дата, время, цена, места, машина, номер (F8, B5, B9).
- [ ] Сначала закрывает камеру, окно, поиск (F6, F7, B6, C6).
- [ ] Карта брони ведёт к брони, профиль туда, откуда открыт (B8, B11).

### Прокрутка

- [ ] Новый экран и шаг открываются сверху (F1, S1).
- [ ] Список после «Назад»: без скелетона, та же страница и место (F2, S7).
- [ ] Обновление не двигает строку под пальцем; статистика не схлопывается (S3, S4).
- [ ] Чат едет вниз, только если человек внизу или пишет сам; поле не закрывает сообщения (F10, S5).
- [ ] Маленькая карта двумя пальцами, страница одним (F11).
- [ ] Высота по Telegram, не `100vh` (S2, S6).

### Закрытие и окна

- [ ] Форма с вводом: вопрос перед закрытием и при «Назад» (F3).
- [ ] Черновик возвращается после закрытия, стирается после отправки (F3, C2, C7).
- [ ] «Sozlamalar» не выбрасывает из пути (F4).
- [ ] Звонок: вопрос при «Назад», микрофон выключен после ухода, сворачивание не рвёт молча (F5, C4).
- [ ] Текст чата стирается после доставки (C3).
- [ ] Свайп вниз на списках включён; на карте, камере, форме, в чате выключен (W1).
- [ ] Ссылка бота открывается один раз; «Yopish» после отзыва и жалобы; загрузка на кнопке отзыва (B10, C1, C5).

### Качество

- [ ] 37 находок `../94` закрыты или решены владельцем иначе, статус в `../94`.
- [ ] Обёртки `Screen`, `BackButton`, `useUnsavedGuard`, `useDraft`, `useListMemory`, `useSwipeClose`: тест на каждую, тест падал до исправления.
- [ ] Стенд: список → карточка → «Назад» на том же месте; форма → закрыть → черновик; звонок → «Назад» → микрофон выключен.
- [ ] Скриншоты до и после F1, F2, F3, F6, F10 (iOS и Android).
- [ ] Стенд 3 прогона, без e2e рядом (урок 86). CI зелёный, ≤150 строк, knip чист.
- [ ] PR, слияние, деплой, проверка владельцем на телефоне.
