# G73. Шрифт DejaVu Sans во всём продукте

> **Кратко:** решение владельца 07.10.2026: весь интерфейс на шрифте **DejaVu Sans**, как на макетах; шрифт задаётся **в одном месте** (конфиг бренда). Делается **после уже запланированных целей**. Причина: макеты нарисованы в DejaVu Sans, системный шрифт Telegram уже и мельче, поэтому сверка Pixel Perfect не сходится (`../137`, строка 7).
