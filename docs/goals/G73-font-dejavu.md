# G73. Шрифт DejaVu Sans во всём продукте

> **Кратко:** решение владельца 07.10.2026: весь интерфейс на шрифте **DejaVu Sans**, как на макетах; шрифт задаётся **в одном месте** (конфиг бренда). Делается **после уже запланированных целей**. Причина: макеты нарисованы в DejaVu Sans, системный шрифт Telegram уже и мельче, поэтому сверка Pixel Perfect не сходится (`../137`, строка 7).

```text
G73. Шрифт DejaVu Sans во всём продукте (решение владельца 07.10.2026)

Ветка goal/g73-font-dejavu от main.

Definition of Done

[ ] Шрифт задан в одном месте: токен шрифта в конфиге бренда
    (brands/<brand>/theme.ts, docs/22). Код берёт его только
    через этот токен; смена шрифта: правка одной строки.
[ ] DejaVu Sans (обычный и жирный) лежит в репозитории как woff2
    (лицензия свободная, файл лицензии рядом), отдаётся с
    Cloudflare Pages; внешних CDN нет (docs/03).
[ ] В шрифте есть все знаки узбекской латиницы: oʻ, gʻ (U+02BB),
    ʼ (U+02BC), «», сум; проверка тестом.
[ ] Шрифт везде: 3 Mini App (переменная --tgui--font-family и все
    экраны со своим CSS), сплэш-экран, лендинг. Логотип остаётся
    Rubik (docs/36).
[ ] Нет мигания и прыжков при загрузке шрифта (font-display,
    preload, G41); размер сборки в бюджете (docs/61).

    шрифта (DejaVu шире системного).
[ ] Сверка Pixel Perfect заново для всех экранов с макетами
    (G58 … G61, G72): наложение и карта разницы.
[ ] Тест на каждый пункт, сначала падает; стенд кусками, полный
    стенд один раз в конце; снимки Android и iOS.
[ ] docs 19, 20, 21, 22 обновлены: шрифт DejaVu Sans вместо
    системного; PR, слияние, деплой; владелец проверил на телефоне.
```

## Заметки

- Это меняет правило `../21` «шрифт системы, как в Telegram». Решение владельца важнее: макеты рисуются в DejaVu Sans.
- Риск: DejaVu Sans шире системного шрифта. Длинные узбекские слова могут не поместиться: поэтому пункт про 320 px.
