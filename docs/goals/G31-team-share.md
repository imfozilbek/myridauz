# G31. Работа команды поровну и дайджест

> **Кратко:** цель владельца 02.10.2026. Ветка `goal/g31-team-share`. Обращения в бот поддержки и заявки водителей делятся поровну между всеми в команде (владелец тоже). В 00:00 по Ташкенту вся команда получает дайджест за сутки. Устройство: `../92`.

## Решения владельца (02.10.2026)

| Вопрос | Решение |
|---|---|
| Кто видит обращение | Только назначенный |
| Владелец в очереди | Да, наравне с модераторами |
| Повтор за день | Тому же человеку, в счёт 1 |
| Дайджест | 00:00 по Ташкенту, всей команде |

## Definition of Done

- Назначение: у кого меньше работы сегодня; ничья: кто дольше не получал. Тест на каждое правило.
- Обращение и заявка водителя приходят только назначенному. Состав команды берётся в момент назначения.
- Ответ на обращение и решение по заявке считаются сделанной работой.
- Дайджест в 00:00 по Ташкенту всей команде, один раз за сутки, пропуск догоняется.
- Тексты дайджеста согласованы, список для носителя здесь.
- Стенд зелёный 3 прогона подряд, без e2e рядом (урок 86). CI зелёный.
- PR, слияние владельцем, деплой, проверка владельцем.

## Тексты для носителя (согласованы владельцем 02.10.2026)

| Ключ | Текст |
|---|---|
| `bot.digest.title` | 📊 Jamoa ishi: {date} |
| `bot.digest.line` | {name}: murojaat {answered}/{total}, ariza {applications} |
| `bot.digest.open` | Javobsiz murojaatlar: {count} |

| Ключ | Текст |

## Проверки

- Тесты: `assignments/domain/pick.test.ts`, `assignments.test.ts`, `digest-text.test.ts`, `drivers/assigned-card.test.ts`, `bots/support-bot.test.ts`.
- Стенд: `bots-team.spec.ts`: обращение видит только назначенный; `/team add`; новые обращения идут тому, у кого меньше работы сегодня.
- Дайджест на стенде не проверяется: Cron стенда не умеет менять время на 00:00. Его проверяют тесты модуля.
