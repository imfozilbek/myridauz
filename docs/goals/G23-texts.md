# G23. Новые тексты на согласие владельца

> **Кратко:** тексты поиска места на карте. Язык: узбекский (латиница), по `../25`. Рядом смысл на русском. Владелец одобряет или правит; носитель проверяет (`../33`). Названия мест не переводятся: их даёт карта OSM.

| Ключ | Текст | Смысл |
|---|---|---|
| `bookings.map.search` | Mahalla, koʻcha yoki moʻljal | Махалля, улица или ориентир (подсказка в поле поиска) |
| `bookings.map.nothing` | Hech narsa topilmadi. Nomni boshqacha yozib koʻring yoki xaritani surib, joyni oʻzingiz toping. | Ничего не найдено. Напишите иначе или подвиньте карту и найдите место сами |
| `bookings.map.searchFailed` | Qidirib boʻlmadi. Internetni tekshirib, qayta urinib koʻring. | Поиск не сработал. Проверьте интернет и попробуйте снова |
| `bookings.map.foundIn` | {kind} · {area} | Вид места и район под названием, например «Bozor, doʻkon · Chilonzor» |
| `bookings.map.kind.mahalla` | Mahalla | Махалля, массив |
| `bookings.map.kind.settlement` | Aholi punkti | Населённый пункт |
| `bookings.map.kind.street` | Koʻcha | Улица |
| `bookings.map.kind.market` | Bozor, doʻkon | Базар, магазин |
| `bookings.map.kind.school` | Maktab, bogʻcha | Школа, детский сад (и вузы) |
| `bookings.map.kind.mosque` | Masjid | Мечеть |
| `bookings.map.kind.health` | Shifoxona, dorixona | Больница, аптека |
| `bookings.map.kind.transport` | Bekat | Остановка, вокзал, метро |
| `bookings.map.kind.place` | Moʻljal | Ориентир (кафе, заправка, банк, парк) |
