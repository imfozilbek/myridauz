# Цели: путь к запуску Rida

> **Кратко:** Документы из `docs/` превращены в цели по порядку. Каждая цель поднимает продукт на шаг. Цели кода готовы, кроме G21 «Ясные экраны» (идёт). Для запуска осталось: цели владельца OPS в конце таблицы.

## Как пользоваться

1. Владелец пишет «дай следующую цель». Claude присылает **одну** следующую
   цель по таблице ниже: весь текст одним блоком кода, чтобы владелец
   скопировал его одной кнопкой (решение владельца 28.09). Владелец
   отдаёт этот текст Claude, и работа по цели начинается.
2. Claude выполняет цель **до конца**: пока все пункты Definition of Done
   не выполнены, не останавливается.
3. После цели Claude отмечает статус здесь и обновляет docs.
4. OPS-цели выполняет владелец, они дают Claude доступы и данные.
5. Каждая цель в своей ветке `goal/gNN-...`. Цель закрыта, когда ветка
   слита в `main` без конфликтов и в `main` всё работает (`../34-git-workflow.md`).
6. В каждой цели есть блок «Проверка владельцем» (`../33-owner-approvals.md`).
   Цель закрыта только после подтверждения владельца. Пока ждём ответа,
   Claude делает всё, что от ответа не зависит.

## Правила для целей

- Одна цель: до 4 000 символов текста, есть Definition of Done.
- Цель ссылается на документы `docs/`, а не копирует их (один источник правды).
- Решение в цели изменилось: сначала обновить профильный документ.
- Статусы: Не начата, В работе, Выполнена, Перенесена.
- Шрифт логотипа: Rubik. Ждёт владельца только вопрос 29 (до 01.03.2027, `../10`), остальные решены.
