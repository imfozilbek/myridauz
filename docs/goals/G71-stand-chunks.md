## Как сделано

- Куски: `scripts/stand/areas.mjs` (8 тем, у каждого файла одна тема; `--area`, `--changed`), тест `areas.test.mjs`.
- Повтор: `scripts/stand/reuse.mjs` (сборка только при изменениях, база с миграциями, карта ссылкой). Подготовка 10 с вместо 69.
- Быстрее сами сценарии: база стенда напрямую (`e2e/stand/stand-tools.ts`, урок №144), шаги по успокоившемуся экрану (`e2e/stand/steps.ts`, урок №143), снимки только с `--shots`.
- Полный стенд: файлы делятся между 4 стендами по времени (`scripts/stand/balance.mjs`).
- Итог 07.10.2026: полный стенд 3 раза зелёный, 118, 126, 122 с (раньше около 260 с). Кусок «регистрация»: 41 с.
- Решение владельца 07.10.2026: остановиться на 2 минутах; минута возможна только на 12 или 16 ядрах (например, GitHub Actions), отдельной целью после запуска.
