# 133. G59: сверка Pixel Perfect с макетом пути попутчика

> **Кратко:** экраны с 3 по 10 пути попутчика (`goals/g59/11-journey-passenger.png`) сверены с кодом попиксельно (уроки №141, №147). Отличие размеров и отступов: не больше 2 px. Остались только отличия данных теста и пять мест, где макет спорит с правилами: они ниже, решает владелец.

## Как сверяем

| Шаг | Что |
|---|---|
| Макет | Телефон из макета вырезается и сжимается до 360 × 776 (карты: 360 × 718, без шапки Telegram) |
| Код | `e2e/g59-pixel.spec.ts` снимает те же экраны с данными макета (`e2e/g59-pixel-mock.ts`) |
| Разница | `scripts/pixel-diff.py`: макет, код и красная карта разницы рядом, доля отличий |
| Замеры | Края карточек и строки текста по столбцу пикселей: положение и ширина слов |
