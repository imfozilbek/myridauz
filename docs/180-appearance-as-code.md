# 180. Оформление ботов и каналов кодом

> **Кратко:** решение владельца 13.10.2026: имена, описания и аватары всех ботов и каналов делает код, в обеих средах, из одного источника в репозитории. Руками больше никто не трогает. Worker каждой среды сам приводит Telegram к репозиторию и меняет только то, что отличается. Цель G82.

## Решение владельца (13.10.2026, вечер)

- «Полное оформление автоматизировано и в internal, и в prod, чтобы руками потом не трогали».
- Утверждённые названия, логотипы и описания уже есть: взять их (выгрузка сессии инфраструктуры).
- Одно и то же в обеих средах: что есть в проде, есть и во внутренней, и наоборот.
- Это меняет решение 3 из `176` («имя, описание и логотип канала код не меняет»).

## Как работает

1. Источник правды: репозиторий (`brands/<бренд>/`, тексты в `packages/i18n`).
2. CI выкладывает код (`179`). Worker своей среды раз в час берёт несколько ботов и каналов, давно не проверенных.
3. Читает, что сейчас в Telegram (`getChat`, `getMyName` и другие).
4. Отличается: ставит из репозитория (`setChatTitle`, `setChatDescription`, `setChatPhoto`, `setMyName` …). Совпадает: ничего не делает.
5. Полный круг: около суток. Новое имя или описание в репозитории доходит до Telegram сам.

## Правила безопасности

- Токены ботов только в Worker, CI их не видит (`32`).
- Смена имени и аватара канала пишет подписчикам служебное сообщение. Поэтому только при отличии, никогда «на всякий случай».
- Аватар: Telegram пережимает картинку, сравнить файлы нельзя. Worker помнит, какой файл какой аватар дал (D1). Первый проход принимает уже стоящий аватар как есть, если он есть: 67 аватаров сверены 13.10 (`176`). Потом аватар меняется, только когда меняется файл в репозитории или кто-то сменил его руками.
- Бесплатный тариф: один запуск Cron делает не больше 50 запросов наружу (`117`), поэтому несколько целей за час.
- Нет права «Изменение профиля канала»: Worker не ломается, «Kanallar» владельца показывает канал без права.

## Что нужно от владельца
