# 13. Мультиязычность (i18n)

Сейчас продукт - **только на узбекском (латиница)**.
Архитектура с первого дня **готова к новым языкам**.
Новый язык = добавить файлы переводов + включить язык в настройке.
Код и архитектура не меняются.

## Коды языков (стандарт BCP 47)

| Код | Язык | Статус |
|---|---|---|
| `uz-Latn` | Узбекский, латиница | Основной, включён |
| `uz-Cyrl` | Узбекский, кириллица | Кандидат |
| `ru` | Русский | Кандидат |
| `en` | Английский | Кандидат |

## Правила для кода

- **Никакого текста прямо в коде.** Любой текст для человека - только
  через ключ: `t('trip.create.title')`.
- Касается всего: 3 бота, 3 Mini App, уведомления, ошибки, посты в каналах.
- Ошибки backend возвращают **код ошибки**, а не текст.
  Текст выбирает клиент по коду.
- Даты, числа, суммы - только через форматтеры на основе `Intl`
  с текущим языком. Никакого ручного форматирования.
- Склонения и множественное число - формат ICU MessageFormat
  (`{count, plural, one {...} other {...}}`).

## Файлы переводов

```
packages/i18n/
  locales/
    uz-Latn/
      common.json   trips.json   bookings.json   chat.json
      driver.json   admin.json   errors.json     notifications.json
  src/
    config.ts       список включённых языков, язык по умолчанию
    translate.ts    функция t()
    format.ts       форматтеры дат, чисел, сумм
```

- Файлы разбиты по темам (namespace). Каждый файл ≤ 150 строк.
- Эталон - `uz-Latn`. Типы ключей генерируются из эталона.
  Если в другом языке нет ключа - ошибка при сборке.

## Язык пользователя

- В базе у пользователя есть поле `locale` (по умолчанию `uz-Latn`).
- При первом входе можно подсказать язык из Telegram (`language_code`),
  но только среди включённых языков.
- Бот и Mini App берут язык из профиля пользователя.

## Данные в базе

- Тексты в базе (названия регионов, районов, городов) - в отдельной
  таблице переводов: `location_translations (location_id, locale, name)`.
- Тексты, которые вводят пользователи (комментарии к поездкам, чат),
  не переводятся.

## Переключатель языка

- Компонент есть с первого дня, но **скрыт**, пока включён один язык.
- Настройка: `enabled_locales: ['uz-Latn']`.
- Добавили язык в список → переключатель появился автоматически.

## Каналы

- Посты в каналах - через те же ключи перевода.
- При новом языке можно открыть отдельные каналы на этом языке.
