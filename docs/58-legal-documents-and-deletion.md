## Где человек видит документы

| Место | Как |
|---|---|
| Регистрация, шаг согласия | 2 галочки на 3 документа, название открывает документ (`118`) |
| Профиль | Раздел «Hujjatlar» |
| Бот попутчиков и бот водителей | Команда `/hujjatlar` (в меню команд): три кнопки, открывают Mini App с `?doc=offer\|privacy\|consent` |

## «Maʼlumotlarimni oʻchirish»

- Профиль → последняя ячейка → экран с объяснением → «Oʻchirish» → «Maʼlumotlaringiz oʻchirildi» → «Yopish» (Mini App начинает с начала).
- API: `DELETE /me` → 204. Нет профиля: `users.not_registered`.
- Что происходит (одним запросом, `apps/backend/src/account-deletion.ts`):

| Данные | Что с ними |
|---|---|
| Живые поездки и брони | Отменяются, как при блокировке (`17`): другая сторона получает сообщение, комиссия возвращается |
| Чаты | Durable Object каждой брони стирает историю. Чат открытой жалобы остаётся до решения: это доказательство (G20, `65` A5). После решения модератора, когда открытых жалоб на эту бронь больше нет, чат стирается (G44) |
| Заявка водителя | Фото машины удаляются, заявка пустая |
| Любимые водители, подписки, «Yaqinlarim» | Удаляются |
| Переписка с поддержкой | Удаляется сразу (без удаления: Cron через 90 дней, `93`) |
| Аватар | Удаляется из R2 |
| Профиль | Имя и телефон стираются, фото и роль водителя снимаются, `deleted_at` ставится (миграция `0015`) |
| Оценки и отзывы | Удаляются: новый аккаунт начинает без старых отзывов (G20) |
| Кошелёк | Строки журнала остаются, две строки `account_deleted` обнуляют бонус и основной счёт: новый аккаунт без старых денег (G20) |
| Решения по жалобам | Остаются без имени и телефона (споры и учёт) |
| Блокировка | Заблокированный не может удалить данные (`DELETE /me` отвечает `users.blocked`). Блок по id остаётся и после удаления |
| Открытая жалоба на человека | Телефон держится в `held_phones`, пока жалобу не решат: блок по жалобе ловит и новый аккаунт с этим номером |
| Публичный id | Меняется: старые ссылки на человека больше не открываются (`65` A3) |
| Точки А и Б (G24) | Стираются сразу во всех бронях и открытых заявках человека (`69`). Район маршрута остаётся |

- После удаления `GET /me` отвечает `unregistered`: человек может зарегистрироваться заново как новый.
- Точки без удаления аккаунта: при отмене, отказе и истечении брони сразу, остальные Cron через 30 дней после поездки, при открытой жалобе после решения. Абзац в «Maxfiylik siyosati» (разделы 2, 4, 6): согласие владельца в G24.
- Тесты: `apps/backend/src/account-deletion-api.test.ts`, `deletion-evidence-api.test.ts`, `modules/complaints/complaint-evidence.test.ts`, `packages/ui/src/account/profile/profile.test.tsx`.
