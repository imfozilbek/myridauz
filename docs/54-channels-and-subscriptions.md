# 54. Каналы, подписки на маршрут, напоминания (как сделано)

> **Кратко:** Новая поездка водителя уходит постом в каналы регионов маршрута; пост меняется, когда мест нет, и удаляется, когда поездка отменена. Попутчик подписывается на поездки, водитель на заявки: бот пишет, когда появится подходящее. Перед поездкой бот напоминает за день и за 2 часа. Сделано в G10 (29.09.2026).

## Каналы (`15`, `37`)

| Что | Как сделано |
|---|---|
| Какой канал | настройка бренда `channels`: код региона СОАТО → @канал (13 каналов, у Ташкента нет) |
| Куда пост | каналы обоих регионов маршрута, без повторов |
| Что публикуем | только поездки водителей; заявки попутчиков нет |
| Кто публикует | бот попутчиков, через очередь `rida-notifications` |
| Вид поста | регионы жирным; районы; дата; отправление и ≈ прибытие; места; цена; машина; «Mashinada ayol bor»; хэштеги регионов (владелец одобрил 29.09.2026) |
| Кнопки | «Joy band qilish»: `startapp=trip_<id>`; «📤 Doʻstga yuborish»: окно Telegram «поделиться» со ссылкой на поездку; «🔔 Shu yoʻnalishga obuna»: `startapp=sub_<регион>_<регион>_<день>` |
| Доверие | «✅ Tekshirilgan haydovchi»: каждый водитель прошёл проверку (`04`). Рейтинг «⭐ 4,8» добавит G11 |
| Контакты | в посте нет: ни телефона, ни имени, ни госномера |
| Последнее место | «🔥 Faqat 1 ta joy qoldi» |
| Мест нет | пост меняется: «⛔ Joy qolmagan», маршрут и день, остаётся только кнопка подписки |
| Поездка началась | пост меняется один раз: «🚗 Safar boshlandi», остаётся только кнопка подписки. Сразу по «Yoʻlga chiqdim» (G63), иначе Cron каждые 15 минут после времени выезда |
| Отмена | пост удаляется (`122`, решение владельца 06.10.2026) |
| Хэштеги | ключи `bot.channel.tag.<СОАТО>`; без «ʻ» (Telegram обрывает хэштег): `#Fargona` |
| Включение | переменная `CHANNEL_POSTS` в `wrangler.toml`: `off` до согласия владельца |

- Id поста хранится в `channel_posts`. Бронь подтвердили, пока пост ждал в очереди: после отправки пост сразу исправляется (сравнение «что показали» и «что сейчас»).

## Подписка на маршрут (`24`)

| Правило | Значение |
|---|---|
| Кто | попутчик: на поездки (бот попутчиков); водитель: на заявки (бот водителей) |
| Что выбирает | откуда, куда (регион или район), дата или «Istalgan kun» |
| «Mashinada ayol bor» | только у попутчика |
| Сколько | до 5 подписок (`MAX_SUBSCRIPTIONS`) |
| «Istalgan kun» | 30 дней, потом бот предлагает продлить; на экране «Muddati tugagan» и «Uzaytirish» |
| С датой | удаляется после даты |
| Частота | одна карточка новостей направления в день (`122` правило 4): первая новость дня со звуком (ночью без), следующие правят ту же карточку без звука (G68) |

- Где подписаться: «Xabar bering» на экране закрытой поездки (`ClosedTrip`) и по ссылке «Shu yoʻnalishga obuna» под постом канала (`SubscribeLink`). Человек выбирает, не печатает.
- С пустого дня поиска «Xabar bering» ушла в G37 (`101`).
- Где список: «Obunalar» внизу раздела «Mening safarlarim» у попутчика и у водителя. На главном экране нет.
- Карточка новостей (G68, макеты g68/1, g68/3): строка на поездку или заявку; кнопки «Hammasini koʻrish» (поиск дня, `?find=`) или «Taklif qilish» (заявки дня, `?requests=`) и «Bu yoʻnalish kerak emas» (подписка кончается прямо из бота, `news_off:<id>`). Подписка кончилась: та же карточка просит продлить (`?subscriptions=1`). Тексты: `152`.
- **Поездка подешевела (G39, `104`):** строка поездки в карточке получает «↓ arzonlashdi», не чаще раза на поездку в сутки (`trips.price_told_at`). Пост канала обновляется при любом изменении времени и цены.

## Напоминания

- Попутчику с подтверждённой бронью и водителю поездки.
- За 2 часа: всегда. За день: только днём по Ташкенту (с 8:00 до 22:00), ночью не пишем.
- Каждое напоминание уходит один раз: таблица `trip_reminders`.
- Cron каждые 15 минут: напоминания и пачки подписок.

## Открытие поездки из канала

- Mini App попутчика читает `tgWebAppStartParam=trip_<id>` и сразу открывает поездку с кнопкой «Joy band qilish».
- «Shu yoʻnalishga obuna» открывает «Xabar bering» для пары регионов: «Faqat <день>» или «Istalgan kun». Прошедший день поста заменяется сегодняшним.
- «Назад» ведёт на главный экран.
- В BotFather у бота попутчиков включено Main Mini App (`https://passenger.myrida.uz`), 29.09.2026.
