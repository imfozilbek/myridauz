# 71. Экран «Qayerdan / Qayerga» поверх карты: только заявка попутчика

> **Кратко:** с G26 (решение владельца 01.10.2026) поиск поездки идёт списками, точки ставятся при брони (`74`). Экран поверх карты остался только для заявки попутчика «Soʻrov qoldirish»: там водитель ещё не выбран, поэтому А, Б и способ нужны сразу. Правила способов и пятаков: `70`.

## Как выглядит

- Карта на фоне, сверху карточка с полями А и Б и способом посадки: «Uyimdan», «Pitakdan», «Farqi yoʻq».
- А заполняется само по месту, где человек стоит, если Telegram даёт место.
- Нажатие на поле: поиск по названию, недавние места, «Mening joylashuvim», карта района, булавка, «Shu yerda».
- Запасной путь без карты: «Roʻyxatdan tanlash» (области и районы, центр района вместо точки).
- Главная кнопка Telegram: «Davom etish».

## Пятак

- Пятак направления система находит сама по паре областей (`72`), на карте виден с расстоянием от А.
- Направления нет в списке: способа «Pitakdan» нет.
