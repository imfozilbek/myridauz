# 71. Заявка попутчика «Soʻrov qoldirish»: списки и карты районов

> **Кратко:** с G35 (решение владельца 03.10.2026, `97`) экрана «Qayerdan / Qayerga» поверх карты больше нет. Заявка идёт так же, как поиск и бронь (`74`): маршрут списками, точки на картах районов. С пустого дня поиска маршрут и день уже известны. Правила способов и пятаков: `70`.

## Шаги

1. **Маршрут:** сразу список «Qayerga», «Qayerdan» по месту человека или списком. С пустого дня поиска шага нет.
2. **День:** «Bugun», «Ertaga», «Boshqa kun». С пустого дня шага нет.
3. **Способ** только там, где у направления есть пятак: «Uyimdan», «Pitakdan», «Farqi yoʻq» (у каждого иконка). Пятака нет: «Uyimdan» без выбора из одного варианта.
4. **Посадка** (кроме «Pitakdan»): карта района отправления, начинается с места человека.
5. **Высадка:** «Qayerda tushasiz?», карта района назначения.
6. **Цена**, потом **итог:** люди 1 по умолчанию с «−» и «+», у точек «Oʻzgartirish».
7. Маршрут, по которому уже ездил или оставлял заявку: способ и точки из прошлого раза, остаются цена и итог.
