# 71. Экран «Qayerdan / Qayerga» поверх карты

> **Решение 01.10.2026:** экран заменяется: маршрут выбирается списками, точки ставятся при брони внутри выбранного района (`74`). Документ описывает код до цели G26; после неё его убираем.
>
> **Кратко:** предложение владельца (30.09.2026). Попутчик выбирает А и Б на одном экране: карта на весь экран, сверху карточка с полями А и Б и способом посадки. Точка сама определяет район по границам: отдельный выбор «регион → район» больше не нужен. Пятак направления система находит сама по списку областей. Правила способов и подбора: `70`. Вопросы владельцу в конце.

## Как выглядит

```
┌────────────────────────────────┐
│ ● A  Chorsu bozori yaqinida    │  карточка сверху
│      Shayxontohur, Toshkent    │
│ ─────────────────────────────  │
│ ◆ B  Qayerga?                  │
│ [Uyimdan] [Pitakdan] [Farqi yoʻq]
└────────────────────────────────┘
          (карта района)
               📍  булавка в центре
      [ Mening joylashuvim ]
┌────────────────────────────────┐
│          Shu yerda             │  главная кнопка Telegram
└────────────────────────────────┘
```

- Карта всегда на фоне. Карточка сверху: поля А и Б, под ними способ посадки.
- Главная кнопка Telegram внизу меняет смысл по шагу: «Shu yerda», потом «Safarlarni koʻrish».
- Родные элементы Telegram, свои только цвета (`21`).

## Шаги попутчика

1. **Открыл поиск поездки. А уже заполнено само:** если человек разрешил место в Telegram, А = где он стоит, с названием и районом («Chilonzor 9 mavzesi yaqinida · Siz turgan joy»). Нажатие на А меняет его. Не разрешил или он вне Узбекистана: А = прошлое А, иначе пусто. Место нужно только чтобы заполнить поле: сервер хранит точку, только когда человек отправил бронь (`69`).
2. **Нажал на поле А.** Выезжает поиск: недавние места, «Mening joylashuvim», поле поиска (районы, махалли, ориентиры, кириллица и латиница).
3. **Выбрал место.** Карта летит туда и обрезается по его району. Булавка в центре, под ней название. Поправил булавку → «Shu yerda». Район определился сам по границам.
4. **Способ посадки:** «Uyimdan» (от двери), «Pitakdan», «Farqi yoʻq» (оба).
   - «Pitakdan»: на карте появляется пятак этого направления (из списка по областям); булавка А не нужна. Если у направления пятака нет, кнопки «Pitakdan» нет.
5. **Нажал на поле Б.** Так же: поиск → карта летит и обрезается по району назначения → булавка у дома → «Shu yerda». Б всегда до дома (`70`).
6. **Карта показывает А и Б**, линию между ними и расстояние: «≈ 310 km». Главная кнопка: «Safarlarni koʻrish».
7. **Дата и время** выбираются на следующем экране, списком (`19`: выбирать, а не печатать).
8. **Список поездок:** только подходящие (`70`), выше те, где водителю ближе.

Можно начать с Б: порядок полей не важен. Любое поле можно поменять нажатием.

## Пятаки по областям

- Пятаки: отдельный список, пятак на каждую пару «область А → область Б»; город Ташкент отдельная область (`70`).
- Экран сам находит пятак по паре областей А и Б и показывает его на карте с расстоянием от А: «Samarqand yoʻnalishi pitagi · 6 km». Выбирать нечего.
- Список ведёт команда в админке: название, точка, направления. Черновик: Claude, проверяют владелец и модераторы.

## Водитель

- Создание поездки тоже поверх карты, но без булавок: поле А (район) → поле Б (район назначения) → способ «Shahar boʻylab yigʻaman», «Pitakdan olaman», «Ikkalasi ham». Пятак водитель не выбирает: система берёт пятак направления из списка по областям (`70`). Точек водитель не ставит.

## Что это меняет

- Выбор «регион → район» (`48`) остаётся только как запасной путь (без карты, если она не загрузилась).
- Точка А и Б ставится **до** брони, при поиске. Приватность та же: водитель до подтверждения видит только окрестность (`70`).
- Срок G25 растёт примерно на 1,5 дня (экран поверх карты). Запуск не отдаляет.
