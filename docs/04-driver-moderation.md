# 04. Модерация водителей

> **Кратко:** Водитель работает только после модерации. Показывает лицо и машину, документы не нужны. Как сделано (экраны, причины, бот, поддержка): `50`.

Стать водителем можно только после проверки командой Rida.

## Заявка (Mini App водителя, 2 экрана: `50`, `118` путь 5)

| Что | Кто видит |
|---|---|
| Аватар (фото лица): обязательно, берётся с регистрации, в заявке его нет (G62), см. `05-avatars.md` | Все |
| Марка, модель, цвет машины (год не спрашиваем: решение владельца 29.09.2026) | Все |
| Число мест для попутчиков (до 7, `35`) | Все |
| Госномер | Пассажир после брони; его близкие, если он поделился поездкой (`43`) |
| Фото машины: спереди с номером, сбоку, салон | Все |

**Документы не запрашиваем** (ни права, ни техпаспорт, ни селфи с правами).
Решение владельца: водитель показывает лицо и машину: этого достаточно.

## Статусы заявки

- `pending`: на проверке.
- `approved`: одобрено.
- `rejected`: отказ с причиной.
- `changes_requested`: нужно исправить (например, «фото номера нечёткое»).
- До отправки заявка в статусе `draft` (фото добавляются). Причины: коды из списка (`50`).

## Процесс

1. Водитель отправляет заявку.
2. Карточка заявки приходит в админ-бот / админ Mini App.
3. Модератор проверяет: лицо хорошо видно; машина на фото = марка, модель,
   цвет и госномер из заявки.
4. Кнопки: «Одобрить» / «Отклонить» / «Попросить исправить».
5. Водитель получает результат от бота водителей; при одобрении бот зовёт в канал области машины и в «Safar eʼlon qilish» (`119`).

## Правила

- Публиковать поездки и принимать брони: только со статусом `approved`.
- Смена машины, госномера или аватара: новая модерация (`50`).
- Модератор может заблокировать водителя в любой момент.
- Фото хранятся в R2.
