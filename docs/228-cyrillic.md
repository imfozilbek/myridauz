# 228. Кириллица во всём продукте (G98)

> **Кратко:** решение владельца 11.11.2026: «Давай глобально переводим все на кириллицу». Тексты пишем латиницей, как сейчас (один источник правды). Кириллицу делает программа: те же слова, только буквы, по правилам `25` и со списком исключений. Пробный перевод 11.11.2026: 2646 строк, 0 ошибок разбора. Кроме файлов перевода переходят имена каналов, места, картинки бренда и сайт. «Да» владельца на все 4 пункта 11.11.2026. Цель: `goals/G98-cyrillic.md`. Готово: на проде с 12.11.2026 (PR #341), «да» владельца на лист экранов, проверено на телефоне.

## Как работает перевод

| Часть | Как |
|---|---|
| Источник | `packages/i18n/locales/uz-Latn/*.json`, 2646 строк, 2084 разных слова |
| Язык `uz-Cyrl` | строится из латиницы при первом обращении к строке; меняются только слова |
| Не меняются | подстановки (`{place}`), формы числа (`plural`, `select`), HTML, ссылки, @имена, /команды |
| Исключения | `locales/uz-Cyrl/exceptions.json`: заимствования, где правило ошибается |
| Остаются латиницей | `locales/uz-Cyrl/keep.json` и бренд из `brands/` |
| Программа | `toCyrillic` из G94 (`packages/i18n/src/cyrillic.ts`), одна для всех мест |

Пробный перевод: латиницей остались только слова из списка «остаются».
