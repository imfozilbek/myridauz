# 196. Другие рынки Узбекистана для логики доски

## Кратко

- Логика Rida: предложение уже публикуется в открытых Telegram-группах; мы собираем его и показываем доской
  (канал на направление); спрос приводим к доске; предложение приходит само, когда слышит «Rida orqali»;
  заработок: платный верх доски (`12`, модель B).
- Исследование 19.10.2026: 13 ниш проверены по 8 условиям; замерены публичные страницы 70 групп и каналов
  (участники, онлайн, посты в сутки); рейтинги TGStat по Узбекистану.
- Вывод: механизм переносится туда, где предложение «на сегодня», сделка закрывается звонком, а поставщик
  борется за верх ленты. Лучшие ниши: грузы между городами, подработка на день, посуточное жильё, оптовые
  продукты. Где покупателю нужны фото и сравнение (машины, телефоны, скот, продажа жилья), побеждают каталоги
  вроде OLX, доска даёт мало.
- Побочная находка: доля «онлайн» от участников выдаёт накрутку. Живая группа: 2 … 13 %. Боты: 40 … 70 %.
  Мёртвый список: меньше 0,5 %.

## Восемь условий механизма

| # | Условие | Почему важно |
|---|---|---|
| У1 | Предложение само публикуется открыто и повторно | Есть что собирать, никого не уговариваем |
| У2 | Спрос ищет «сейчас» по 2 … 3 параметрам | Доска текстом отвечает за секунды |
| У3 | Сделка закрывается звонком | Внутри нет оплаты, доставки и споров |
| У4 | Поставщик выигрывает от позиции в ленте | Платит за верх доски |
| У5 | Единица = физический ресурс | Машина, грузовик, квартира на дату, рабочий на день |
| У6 | Нет сильного игрока в слое «сейчас» | OLX про долгие объявления, Yandex про город |
| У7 | Данные публичные и остаются в Telegram | Решение владельца и юриста (`30`, Р7) |
| У8 | Объявление раскладывается в строку без фото | Маршрут, время, цена, место |

## Проверка живости группы по доле «онлайн»

| Доля онлайн | Что это | Примеры |
|---|---|---|
| 2 … 13 % | Живые люди | Yakkabogʻ 7 %, Buxoro Toshkent yuk 5 %, Работа Самарканд 4 %, Yuk markazi 13 % |
| 40 … 70 % | Купленные боты «онлайн» | Jizzax taksi 67 %, Telefon bozor 44 %, Urganch Nukus 45 % |
| Меньше 0,5 % | Мёртвые или накрученные списки | Qarshi ISHBOR 0,2 %, Kvartira Toshkent 0,5 %, Rishton Toshkent 0,3 % |

Правило: перед выбором группы-источника смотреть долю онлайн, потом сутки экспорта и разбор, как для Yakkabogʻ.

## Рекомендация

1. Сначала добить попутки: механизм подтверждён, направлений с десятками тысяч участников много (G80).
2. Вторая ниша тем же кодом: грузы между городами. Та же строка «откуда, куда, когда, машина, 📞», те же окна
   дня, те же каналы-доски. Первый шаг: сутки экспорта группы Buxoro Toshkent yuk (31 тыс., 5 % онлайн) и разбор.
3. Третья: подработка на день в областях («ish bugun») через ilk•ish, посуточное жильё через Uyim. Обе сначала
   измерить суткой экспорта.
4. Не брать: машины, телефоны, скот, продажа жилья. Там побеждает каталог с фото.
