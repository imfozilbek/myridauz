# 204. G73: шрифт DejaVu Sans во всём продукте

> **Кратко:** решение владельца 07.10.2026, выбор владельца 19.10.2026 после сравнения на главном экране. Весь продукт на **DejaVu Sans**, как на утверждённых макетах: 4 Mini App, сплэш, картинки для «Ulashish», лендинг. Шрифт задан одной строкой в теме бренда. Отличия кода от утверждённых макетов упали примерно вдвое. Логотип остаётся Rubik.

## Как устроено

| Что | Где |
|---|---|
| Имя шрифта | `font: 'dejavu-sans'` в `brands/<brand>/theme.ts`: одна строка (`22`) |
| Файлы | `brands/<brand>/public/fonts/dejavu-sans/`: обычный и жирный, латиница и кириллица (по 12 … 13 КБ woff2), `font.css`, `LICENSE.txt` |
| Сборка файлов | `brands/rida/brand-kit/tools/web-font.py` из DejaVu Sans 2.37 (`fonts-dejavu-core`), без hinting (телефоны рисуют без него) |
| Где шрифт берёт код | `fontStack`, `fontHead` в `brands/font.ts`; переменная `--tgui--font-family` на корне приложения (`themeVars`); картинки canvas (история, момент, QR, карточка поездки): `usePictureFont`, сначала грузит оба веса |
| Отдаёт | Cloudflare Pages каждой Mini App и лендинг (своя копия папки), без внешних CDN (`03`) |
| Без мигания | лицо шрифта и латинские файлы в `<head>` каждой страницы (`preload`), `font-display: block`; сплэш уходит, только когда шрифт на месте (`use-splash.ts`, G41) |
| Кириллица | отдельные файлы: грузятся, только если на экране есть кириллица (имя человека) |
| Размер | первая загрузка Mini App плюс 25 КБ (два латинских файла) к 227 КБ кода (`106`); бюджет не меняется (`61`) |
| Шрифт телефона | остаётся у кнопок Telegram внизу (их рисует Telegram), у эмодзи и редких знаков, которых нет в DejaVu Sans |
| Остаётся как было | логотип Rubik (контур SVG, `36`), номер машины и коды моноширинным шрифтом, подписи карты MapLibre (`67`) |

Другой шрифт: новая папка с теми же файлами (`web-font.py`) и одна строка `font` в теме.

## Сверка Pixel Perfect заново (19.10.2026)

Как: макет из HTML (`goals/g58/src`, `goals/g76/src`) или телефон из утверждённой картинки PNG; телефон в левом верхнем углу, целые пиксели; код из `e2e/*-pixel.spec.ts`; `scripts/pixel-diff.py`: «Maket», «Kod», «Ustma-ust», «Farq». Макет рисуется без правила Inter контейнера (урок №352). «До» это код со шрифтом системы.

| Лист | До | После | ≤ 3 % |
|---|---|---|---|
| G58 регистрация, 4 телефона | 4,51 … 5,12 % | 1,29 … 2,46 % | да |
| G72 сплэш (g66/5) | шрифт системы | 2,82 % | да |
| G76 попутчик, 14 телефонов | 3,71 … 9,40 % | 0,85 … 2,96 % | да |
| G76 попутчик, телефон 9 | 10,24 % | 8,01 % | спор 3 `167`, решение владельца |
| G76 водитель, 16 телефонов | 4,23 … 6,93 % | 1,29 … 2,76 % | да |
| G60, G61 | 6,5 … 15 % | 3,6 … 14 % | экраны потом меняли G63, G64, G69, G75 с согласия владельца; буквы совпадают |

- Ширина слов кода и системного DejaVu Sans совпадает до пикселя (замер в браузере).
- Остаток отличий: сглаживание краёв, сдвиги до 1 px и данные (фото, иконка машины вместо буквы).

## Размеры 320, 375, 430 px (`121`)

- DejaVu Sans шире шрифта телефона: «Mening safarlarim» на плитке теперь в две строки, как на макете g76.
- Две строки с размером от ширины экрана получили запас 3 px: прогресс дела «Navbat» и «Havolani yoʻlovchilarga yuborish» (урок №355).
- Все снимки экранов (293 теста, Android и iOS), проверки «ничего не обрезается» на 320, 375 и 430 px (`e2e/sizes.ts`) и smoke (51 тест) зелёные 19.10.2026.
