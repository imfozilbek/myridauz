# 77. Сценарии попутчика

> **Кратко:** все пути попутчика (часть каталога `76`). Задача попутчика: доехать в другой город дёшево, безопасно и без лишних звонков. Проверка: файл стенда `e2e/stand/...`, unit-тест или «нет» (пробел, в работе G27).
