# 38. Бренд-пакет: все случаи и моушн

> **Кратко:** Полный бренд-пакет Rida для всех мест, где нас видят: логотипы, Telegram, сайт, соцсети, печать, моушн-видео и слои для моушн-дизайнера. Всё собирается одним генератором `brands/rida/brand-kit/`.

Решение владельца: делаем полный пакет сейчас (27.09.2026), хотя G01 ещё не начат.
Брендбук: https://claude.ai/artifact/VMadfyDq12GCMDSK1DD7Zc
Архив: `rida-brand-kit.zip` (131 файл) отправлен владельцу.

## Суть бренда

1. **Вместе в дорогу.** Rida не такси: попутчики делят расходы (`01`).
2. **Как сам Telegram.** Отличие только в цветах (`21`).
3. **Безопасно.** Проверенные водители, «Mashinada ayol bor», скрытые контакты.
4. **Спокойно и коротко.** Голос Rida (`20`).

## Фирменные элементы

| Элемент | Где |
|---|---|
| Плитка «R» (`36`) | Везде: главный знак |
| Номер «код \| R» (`36`, `37`) | Каналы, реклама регионов |
| Линия маршрута: бирюзовая точка старт, пунктир, янтарная точка финиш | Посты о поездках, сторис |
| Янтарная черта рядом со слоганом | Логотип, заголовки, картинки |

## Моушн: принципы

- Мягко и точно: плитка «выпрыгивает», текст спокойно выезжает, линии рисуются.
- Ничего не мигает и не крутится.

| Токен | Значение | Где |
|---|---|---|
| `duration.micro` | 150 мс | Нажатие, переключатель |
| `duration.ui` | 250 мс | Переходы экранов и шторок |
| `duration.brand` | 600 мс | Появление плитки «R» |
| `duration.hold` | 450 мс | Пауза между шагами в видео |
| `ease.out` | cubic-bezier(0.22, 1, 0.36, 1) | Текст, линии |
| `ease.pop` | back-out, отскок 1.7 | Плитка, точки, кнопки |

## Генератор

- `brands/rida/brand-kit/`: см. его `README.md`. Одна команда собирает весь
  архив (131 файл), без ручных шагов.
- Цвета: только `brands/rida/theme.ts` (`colors` из `20` и вспомогательные `art` для
  иллюстраций). `data/tokens.json`: для чего каждый цвет и моушн-токены.
- Цифры в картинках берём из документов: цены `16`, бонус `12`.
- Шрифт Rubik не содержит знак ʻ: генератор рисует его знаком ‘ из Rubik (`36`).
- Генератор входит в монорепо (G02): ESLint, 150 строк, knip. CI собирает архив на каждый
  PR и в `main`, скачать: артефакт `brand-kit` в запуске CI (`45`). Результат совпадает
  с локальной сборкой байт в байт (проверено 28.09.2026).
- Рекламный ролик собирает тот же пакет: `promo/` (`41`).
