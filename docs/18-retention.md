# 18. Удержание людей на платформе

**Принцип (решение владельца): держать людей в Rida максимально.**
Каждая фича проверяется вопросом: «Не уводит ли это людей из Rida?»

## Два способа удерживать

1. **Закрыть пути ухода**: трудно договориться в обход Rida.
2. **Дать причины остаться**: в Rida удобнее и безопаснее, чем без неё.

## 1. Закрыть пути ухода

| Мера | Статус |
|---|---|
| Чат и звонки внутри Rida, без номеров (`07`, `08`) | Решено |
| Комиссия не возвращается, если бронь отменил водитель (`12`) | Решено |
| **Маскировка контактов в чате** всегда: номера, @username, ссылки → «***» | Решено |
| **Прямые контакты не раскрываются никогда**: только чат и звонок в Rida | Решено |

## 2. Дать причины остаться

### Безопасность (главная причина для женщин)

- Фильтр «Mashinada ayol bor» (`06`).
- Проверенные водители: модерация лица и машины (`04`).
- Жалобы и блокировки (`17`): **работают только для поездок в Rida**.
- «Поделиться поездкой» с родственниками: ссылка с маршрутом, машиной,
  временем выезда. Предложено.

### Доверие

- **Рейтинг и отзывы** после поездки (водитель ⇄ попутчик).
  Рейтинг есть только в Rida: вне Rida его нет. **Решено** (`24`).
- История поездок в профиле. Предложено.

### Удобство

- **«Любимый водитель»**: попутчик сохраняет водителя и видит его
  новые поездки. Повторная поездка: снова через Rida. Предложено.
- **Подписка на маршрут**: бот сообщает о новой поездке по маршруту
  (например, Ташкент → Яккабаг). **Решено** (`24`).
- Напоминания о поездке: за день и за 2 часа. Предложено.

### Для водителя

- Больше попутчиков, чем в обычных чатах Telegram.
- Бонус 1,5 млн сум за первые месяцы (`12`).
- Высокий рейтинг → выше в поиске. **Решено** (`24`).

## Что не делаем

- Не показываем контакты в каналах (`15`).
- Не даём ссылок на внешние чаты и группы.
