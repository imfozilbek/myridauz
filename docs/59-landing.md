# 59. Лендинг myrida.uz (G15)

> **Кратко:** Полноценный лендинг на узбекском: за один взгляд понятно, что это, как работает и сколько стоит. Картинки из рекламного ролика, 5 интерактивов, живые цены из API. Страницы собираются в HTML при сборке, скрипт 4 КБ внутри страницы. Бренд только из `brands/<brand>/`. Сделано в G15 (30.09.2026).

## Что на странице (сверху вниз)

| Раздел | Что там | Интерактив |
|---|---|---|
| Первый экран | Слоган, «Viloyatlararo birga safarlar», 2 кнопки в ботов, машина с 4 людьми на дороге Toshkent → Samarqand | Машина мягко «едет» |
| «Tanish holatmi?» | 5 болей: ожидание, цена в праздники, чужой водитель, женщина в машине, пустая обратная дорога | Переключатель «Oldin / Rida bilan», сам переходит на «Rida bilan» |
| «Qanday ishlaydi» | 4 шага попутчика и 3 шага водителя, у каждого свой экран Mini App в телефоне | Вкладки и шаги, шаги сами листаются, пока человек не нажал |

- Без JavaScript страница целая: видны обе стороны болей, все шаги, карта без цен.
- «Меньше движения» в телефоне: анимации и автопрокрутка выключены.

## Цены: только живые

- API `GET /public/directions` (`api.<domain>`): главные направления из Ташкента, км и цена.
  Та же рекомендация, что в Mini App (`23`). Без подписи, без личных данных, кэш 1 час.
- CORS только для `<domain>` и `www.<domain>`.
- Нет ответа API: строки цены скрыты. Придуманных цифр на сайте нет.

## Картинки

| Файл | Откуда |
|---|---|
| `hero.webp`, `crowd.webp` | Сцены ролика: дорога с машиной, толпа «R» (`41`) |
| `phone-*.webp` (7 экранов) | Экраны Mini App из ролика: поиск, результаты, поездка, чат, публикация, заявки, Telegram |

- Генератор: `pnpm --filter @platform/brand-kit-rida landing` (нужен Chromium).
  Файлы в `brands/<brand>/landing/art/` (в git), от 16 до 48 КБ.
- Карта: `brands/<brand>/brand-kit/data/uzbekistan.json` с кодами SOATO регионов.

## Как устроено

| Часть | Где |
|---|---|
| Разделы | `apps/landing/src/sections/` |
| Скрипт | `apps/landing/src/client/` (собирается `vite.client.ts`, вставляется в страницу) |
| Стили | `apps/landing/src/styles/` |
| Сборка | `vite build` собирает `prerender.ts`, он пишет HTML в `apps/landing/dist` |
| Тексты | `packages/i18n/locales/uz-Latn/landing.json`, документы: `legal.json` (`58`) |
| Деплой | `scripts/deploy.mjs`: Pages `<brand>-landing`, домены `<domain>` и `www.<domain>` |
