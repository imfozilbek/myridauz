# 59. Лендинг myrida.uz (G15)

> **Кратко:** Полноценный лендинг на узбекском: за один взгляд понятно, что это, как работает и сколько стоит. Картинки из рекламного ролика, 5 интерактивов, выбор маршрута со ссылкой в Mini App, живые цены из API. Страницы собираются в HTML при сборке, скрипт 4 КБ внутри страницы. Бренд только из `brands/<brand>/`. Сделано в G15 (30.09.2026).

- Без JavaScript страница целая: видны обе стороны болей, все шаги, карта без цен.
- «Меньше движения» в телефоне: анимации и автопрокрутка выключены.

## Цены: только живые

- API `GET /public/price?from=&to=` (`api.<domain>`, id мест): км и цена для выбранной пары.
  Та же рекомендация, что в Mini App (`23`). Без подписи, без личных данных, кэш 1 час.
- CORS только для `<domain>` и `www.<domain>`.
- Нет ответа API: строки цены скрыты. Придуманных цифр на сайте нет.

## Маршрут из сайта в Mini App

- Кнопка ведёт на `t.me/<бот попутчиков>?startapp=find_<SOATO откуда>_<SOATO куда>`.
- Mini App (`packages/ui/src/market/find-link.tsx`) открывает поиск с этим маршрутом на шаге «день».
- Новый человек сначала регистрируется (`47`), потом сразу видит поиск с тем же маршрутом.

## Аналитика

- Cloudflare Web Analytics включена для всей зоны `myrida.uz` с автоустановкой. В коде ключа нет.
- Скрипт `beacon.min.js` Cloudflare вставляет только в ответ браузеру. Проверка: `curl -H "Accept: text/html" -H "User-Agent: Mozilla/5.0"`, простой `curl` его не видит.
