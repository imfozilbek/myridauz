## 3. Вопрос 3 простыми словами

Эти числа Claude поставил в коде, чтобы защитить людей и сервер; владелец подтвердил их 06.10.2026. Пример: отзыв не длиннее 300 знаков, чтобы никто не вставил в отзыв целую страницу. 
| Лимит | Значение | Зачем |
|---|---|---|
| Номер телефона свежий при регистрации | 1 час | чужой старый номер не подставить |
| Марка и модель машины | 2 … 32 знака | без мусора в названии |
| Живых броней на одну поездку | 1 | один человек не займёт места дважды |
| Предложений водителя на одну заявку | 1; живёт, пока открыта заявка или до своего выезда | без спама одному попутчику |
| Комментарий к поездке; отзыв; жалоба | до 200; 300; 500 знаков | коротко и читаемо |
| Картинка для истории | до 1 МБ | быстро грузится |
| Попытка дать контакт | каждая 3-я: сигнал команде | ловим обход Rida |
