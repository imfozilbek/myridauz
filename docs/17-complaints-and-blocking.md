# 17. Жалобы и блокировки

> **Кратко:** Любой участник может пожаловаться. Модератор решает: предупреждение или блокировка по Telegram ID и телефону.

Любой участник может пожаловаться на другого. Модератор проверяет жалобу
и при необходимости блокирует человека.

## Кто на кого может жаловаться

- Попутчик → водитель, водитель → попутчик, попутчик → попутчик.
- Только если люди связаны: общались в чате или едут в одной поездке.
- Одна жалоба от одного человека на одну поездку/чат.
- Тот, на кого жалуются, **не видит**, кто пожаловался.

## Причины жалобы (выбор из списка + комментарий)

| Код | Причина | Приоритет |
|---|---|---|
| `harassment` | Приставания, оскорбления, угрозы | Высокий |
| `unsafe_driving` | Опасное вождение | Высокий |
| `fake_profile` | Чужое фото, неверный пол | Высокий |
| `no_show` | Не пришёл / не приехал | Обычный |
| `car_mismatch` | Машина или номер не совпадают | Обычный |
| `price_changed` | Требовал больше, чем договорились | Обычный |
| `spam_fraud` | Спам, мошенничество | Обычный |
| `other` | Другое | Обычный |

Тексты причин: через ключи перевода (`13-i18n.md`).

## Что видит модератор (админ Mini App)

- Жалоба: причина, комментарий, поездка, время.
- Профили обеих сторон: **аватары** (включая фото попутчика: `05-avatars.md`),
  машина, история поездок, прошлые жалобы.
- Переписка из чата: **только по этой жалобе** (доступ записывается в журнал).

## Статусы жалобы

`new` → `in_review` → `resolved`

## Решения модератора

| Решение | Что происходит |
|---|---|
| Без действий | Жалоба закрыта |
| Предупреждение | Человек получает сообщение от бота |
| Временная блокировка | На N дней нельзя пользоваться Rida |
| Постоянная блокировка | Доступ закрыт навсегда |

- Автор жалобы получает общий ответ: «Жалоба рассмотрена». Без деталей.

## Что делает блокировка

- Все боты и Mini App отвечают: «Аккаунт заблокирован».
- Активные поездки и брони отменяются, другие стороны получают уведомление.
- Блок по Telegram ID **и** номеру телефона (защита от нового аккаунта).

## Автоматические правила (настройки в админке)

- Жалоба с высоким приоритетом: сразу уведомление модераторам в админ-бот.
- 3+ жалобы от разных людей за 30 дней: профиль скрыт из поиска
  до решения модератора.

## Модуль в коде

- `modules/complaints` (жалобы) и `modules/moderation` (решения, блокировки).
