# 127. Все лимиты для людей: один список

> **Кратко:** проход 06.10.2026 по коду и документам. Здесь все лимиты, в которые может упереться попутчик, водитель, близкий или команда. Колонка «Где» показывает: в коде и в документах одно и то же («код»), решено, но ещё не в коде («решено»), есть только в коде без решения («только код»). Споры и решения владельца: `128`. Лимиты людей меняет владелец в админке «Cheklovlar» (`128` §4, G67). Источник значений в коде: `brands/rida/brand.config.ts` и `packages/contracts`.
