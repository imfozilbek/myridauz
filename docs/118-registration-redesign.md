- Рисунок делает генератор из исходных фото `brands/<бренд>/public/regions/`: линии цвета приложения на светлом фоне. Попутчик: бирюзовый, водитель: янтарный. Цвета из `theme.ts` бренда, руками не правим (урок №10).
- Генератор вырезает кадр без значка ✦ в углу фото.
- Текст никогда не лежит на картинке: название под рисунком на белом фоне.
- Где: выбор области (14 карточек), строки направлений, шапка «Safarlar», заявки у водителя. Вид строк направлений решаем вместе с главным экраном.

## Главный экран попутчика (решение владельца 06.10.2026)

- Плитки остаются (как G53), нижнего меню нет (макет `goals/g66/1-passenger-home.png`). Поиск и направления живут на экране поиска (путь 2), не на главном.
- Сверху: профиль; карточка поездки из пути 3 (если есть); 4 плитки. Плитки «умные»: «Soʻrov qoldirish» становится «Soʻrovim» (куда, когда, число предложений), «Oxirgi yoʻnalish» после поездки становится «Qaytish».
- Строка «Haydovchi boʻling» (янтарная) под плитками открывает приложение водителя; скрыта, если человек уже водитель или есть активная поездка.
- Внизу к кнопке «Safar topish» прикреплён блок «Qayerdan / Qayerga»: «Qayerdan» сам по местоположению (иначе последнее место), ⇅ меняет местами, «Qayerga» открывает направления с рисунками и показывает число поездок.
