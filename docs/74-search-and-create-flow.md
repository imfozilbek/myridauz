# 74. Поиск и создание поездки: сначала списки, точки потом

> **Кратко:** решение владельца 01.10.2026. Водитель и попутчик выбирают маршрут **списками**: область (одна из 14), потом район. Попутчик видит все поездки по этому маршруту и выбирает одну. **Точки на карте он ставит только при брони и только нужные:** посадку, если водитель забирает из дома; высадку всегда. Карта и поиск места показывают только выбранный район. Заменяет порядок шагов из `71` (экран поверх карты). Правила пятаков и совпадения способов: `70`. Делаем отдельной целью G26.

## Три правила

| # | Правило |
|---|---|
| 1 | **Маршрут выбирают списками:** область, потом район. Без карты |
| 2 | **Способ посадки задаёт водитель.** Попутчик выбирает его, только если водитель готов к обоим |
| 3 | **Точка ставится внутри выбранного района.** Карта обрезана по нему, поиск ищет только в нём |

## Водитель создаёт поездку

1. **Qayerdan:** область, потом район. Если человек уже разрешил доступ к месту, область и район выбраны сами; можно поменять.
2. **Qayerga:** область, потом район.
3. **«Yoʻlovchilarni qayerdan olasiz?»**
   - «Shahar boʻylab yigʻaman»: забирает каждого из дома;
   - «Pitakdan olaman»: ждёт на пятаке, собирает всех и уезжает;
   - «Ikkalasi ham»: оба способа.
4. **Пятак водитель не выбирает.** Система сама берёт пятак направления «область А → область Б» и показывает: название, точку на карте. Направления нет в списке пятаков: кнопки «Pitakdan olaman» нет.
5. **Точку на карте водитель не ставит.** Ни для посадки, ни для высадки.
6. Дальше как сейчас: дата, время, места, цена, «Mashinada ayol bor», комментарий, проверка, «Eʼlon qilish».

## Попутчик ищет и бронирует (короткий путь G35, `97`)

1. **«Safar topish» или «Qayerga borasiz?»** на главном: сразу список областей «Qayerga», потом район (или «Butun viloyat»).
2. **Qayerdan** берётся по месту, где человек стоит. Места нет: список «Qayerdan» открывается сам.
3. **Сразу поездки ближайшего дня с поездками:** сегодня, иначе завтра. День меняется на экране результатов: «Bugun · Ertaga · Boshqa kun». Без экрана «Qaysi kuni?» и без «Davom etish».
4. **Выбирает поездку,** открывает её, главная кнопка «Joy band qilish».
5. **Способ,** только если водитель готов к обоим: «Uyimdan» или «Pitakdan».
6. **Посадка:**
   - с пятака: точку не спрашиваем, показываем пятак на карте;
   - из дома: «Qayerdan olib ketsin?» Карта района отправления начинается с места человека, если Telegram его даёт; поиск только в районе.
7. **Высадка всегда:** «Qayerda tushasiz?» Карта района назначения. Центр района вне его границы: карта сама переходит внутрь.
8. **Итог «Joy soʻrash»:** 1 человек по умолчанию, «−» и «+»; у точек «Oʻzgartirish». Отправка. После брони точки не меняются: только отмена и новая бронь (`70`).
9. **Второй раз по тому же маршруту:** точки и способ из прошлой поездки, итог открывается сразу. На главном «Oldingi yoʻnalishlar»: одно нажатие до поездок.
10. **Пустой день:** главная кнопка «Soʻrov qoldirish», других призывов нет (G37 R9). Заявка берёт маршрут и день из поиска; остаются способ (если есть пятак), точки, цена и итог. Вторая открытая заявка на тот же маршрут и день не создаётся: «Soʻrovni ochish» открывает первую (G37 R5).

## Пример

Попутчик в Ташкенте, едет в Ургут:

| Шаг | Что видит | Что делает |
|---|---|---|
| Qayerdan | «Toshkent shahri · Chilonzor» (выбрано само) | Ничего |
| Qayerga | 14 областей | «Samarqand viloyati», потом «Urgut» |
| Поездки | 5 поездок Ташкент → Ургут на завтра | Выбирает поездку «по домам» |
| Посадка | Карта Ташкента, поиск только по Ташкенту | «Chilonzor 9», «Shu yerda» |
| Высадка | Карта Ургута, поиск только по Ургуту | Своя махалля, «Shu yerda» |

## Система

| Что | Как |
|---|---|
| Поиск поездок | По району А и району Б. «Butun viloyat» находит все районы области |
| Ташкент | Город Ташкент одна зона: поездка из любого его района подходит попутчику из любого района города (уже так, `place-match.ts`) |
| Порядок списка | По времени выезда. Способ не фильтрует: попутчик видит все поездки и способ на карточке |
| Пятак | Сам по направлению «область А → область Б» из списка живых направлений (`70`, `72`) |
| Совпадение способов | Таблица `70`: попутчик выбирает способ только у поездки «оба» |
| Поиск места | Только внутри зоны поездки: её район или город Ташкент целиком (`GET /map/search?zone=`) |
| Карта точки | Обрезана по той же зоне; точку за границей не поставить |
| Проверка точки | Сервер проверяет: точка внутри зоны поездки (`pointFits`) |
| Место человека | Только чтобы заполнить «Qayerdan» и сдвинуть карту; сервер хранит точку, когда отправлена бронь |
| Приватность | Водитель до подтверждения видит окрестность и лишний путь; точку после подтверждения (`70`) |
| Заявки у водителя | Выше те, кого удобно взять вместе (лишний путь, `70`). День на экране заявок: «Bugun · Ertaga · Boshqa kun»; пустой день ведёт к «Safar eʼlon qilish» с маршрутом и днём (G37, `101`) |
| Хранение точек | Как сейчас (`69`) |

## Где в коде (сделано в G26)

| Часть | Где |
|---|---|
| Поиск списками, «Qayerdan» по месту | `ui/market/find-trip-flow.tsx`, `ui/places/route-screen.tsx`, `use-here.ts` |
| Бронь: места, способ, точки, проверка | `ui/bookings/book-flow.tsx`, `book-point.tsx`, `book-review.tsx` |
| Карта точки в зоне | `ui/way/point-screen.tsx` (`zone`), `use-clip.ts` |
| Пятак у водителя на карте | `ui/market/trip-mode-step.tsx`, `ui/map/pitak-map.tsx` |
| Поиск места в зоне, граница области | `GET /map/search?zone=`, `GET /map/borders/:id` (область = все её районы) |
| Зона | `contracts/route-rule.ts` `zoneOf` |
| Поиск поездок без способа и точек | `backend/trips/application/read.ts` |

Зона точки: **зона поездки** (её район или весь город Ташкент), не выбор попутчика в поиске: так проверяет сервер, и бронь по ссылке работает так же. Экран поверх карты остался только у заявки «Soʻrov qoldirish» (`71`).

## Решения владельца 01.10.2026

1. Попутчик выбирает и «откуда» (область и район); по месту заполняется само.
2. На карте посадки есть поиск, но только внутри района отправления.
3. Водитель может выбрать оба способа сразу.
