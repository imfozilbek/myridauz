# 23. Движок цен: одно место для формулы

> **Кратко:** Формула цены и её переменные живут в одном месте (админка). Изменили переменную, и цены сразу пересчитались.

## Принцип (решение владельца)

- Рекомендованная цена по каждому направлению **легко меняется**.
- Формула и её переменные живут **в одном месте**. Изменили переменную,
  все рекомендации сразу считаются по-новому.
- Динамическое ценообразование (по спросу и т.п.): позже, без переделки.

## Формула (сейчас)

```
есть ручная цена направления → она
иначе: цена = км × ставка, округлить до шага
ограничить: min … max
```

## Переменные (настройки в админке, не в коде)

| Переменная | Сейчас | Что делает |
|---|---|---|
| `rate_per_km` | 357 сум | Базовая ставка за км |
| `round_step` | 5 000 сум | Шаг округления |
| `min_price` / `max_price` | 30 000 / 600 000 | Пределы цены за место |

- Множители (выходные, праздники, спрос) **не делаем сейчас**: без кода
  на будущее (`11`). Добавятся новой стратегией, остальной код не меняется.

## Архитектура (модуль `pricing`)

- **Одна функция** считает рекомендацию: `recommendPrice(route, date)`.
  Её используют все: боты, Mini App, каналы.
- Формула: **стратегия** (сменный блок): сейчас только `per-km`. Выбор стратегии: настройка бренда (`22-multi-brand.md`).
- Переменные хранятся в базе, кэшируются. Изменение в админке →
  кэш сбрасывается → новые цены сразу.

## Таблица цен по направлениям в админ Mini App (решение владельца)

- В админ Mini App есть таблица направлений: откуда → куда
  (регион или район) и **предлагаемая цена**.
- Админ может задать цену для любого направления вручную. Ручная цена
  важнее формулы.
- Нет ручной цены: работает формула.
- Стартовое наполнение: таблица v3 (`16-start-prices.md`).

## Безопасность изменений

- **Предпросмотр:** перед сохранением админ видит таблицу «было → стало»
  по главным направлениям.
- **История:** каждое изменение переменных сохраняется (кто, когда, что).
  Можно откатить на прошлую версию.
- Уже опубликованные поездки **не меняются**: новая рекомендация только
  для новых поездок и заявок.
