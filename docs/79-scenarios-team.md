# 79. Сценарии команды: модератор, админ, владелец

> **Кратко:** все пути команды Rida (часть каталога `76`). Задача модератора: пускать только честных водителей и быстро разбирать жалобы. Задача владельца: держать цены, команду и кошельки под контролем. Проверка: файл стенда, unit-тест или «нет» (пробел, в работе G27).
