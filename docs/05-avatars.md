# 05. Аватары

> **Кратко:** Аватар водителя обязателен и проверяется. Фото попутчика видят только попутчики той же поездки и модераторы, водитель никогда.

## Правила по ролям

| Роль | Аватар | Модерация |
|---|---|---|
| Водитель | **Обязателен.** Без него заявка не уходит на модерацию | Да |
| Пассажир | На старте: по желанию. Позже: обязателен | Позже |

## Водитель

- Аватар: главный способ показать лицо (документы не запрашиваем).
- Смена аватара: повторная модерация аватара.

## Пассажир

- Обязательность включается настройкой `passenger_avatar_required`,
  без переделки кода.
- **Решено: фото попутчика видят только другие попутчики.**
  - Водитель не видит фото попутчика никогда: ни до брони, ни после.
  - Другие попутчики видят фото, если едут в той же поездке
    и их бронь подтверждена.
  - **Модераторы** видят фото всегда: для проверки жалоб и блокировок
    (`17-complaints-and-blocking.md`).

## Требования к фото

- Лицо хорошо видно.
- Без тёмных очков и маски.
- В кадре нет других людей.

## Хранение

- Cloudflare R2 (приватный), сжатие на клиенте. Как устроено: `47`.
