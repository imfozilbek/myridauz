# 05. Аватары

> **Кратко:** фото лица водителя обязательно с регистрации и видно другим после проверки (G58, `118`). Фото попутчика по желанию: видно сразу, команда проверяет его после, «Mos emas» его убирает (решение владельца 19.10.2026, G51). Фото попутчика видят только попутчики той же поездки и модераторы, водитель никогда.

## Правила по ролям

| Роль | Аватар | Проверка |
|---|---|---|
| Водитель | **Обязателен** с регистрации | Да: одобренная заявка одобряет и фото; новое фото проходит проверку фото, права водителя остаются (G91 DRV-1) |
| Пассажир | **По желанию** (решение владельца 19.10.2026, G51; было: обязателен с 06.10.2026) | Да, **после**: фото видно сразу, команда проверяет каждое новое |

## Проверка фото (G58)

- Пользоваться Rida можно сразу, ничего не ждать.
- Фото водителя ждёт команду: сам водитель видит фото и строку «Rasm tekshirilmoqda», другие видят его без фото.
- Фото попутчика видно сразу тем, кому положено (ниже), без строки «tekshirilmoqda». Команда проверяет его после (G51).
- «Mos emas» у попутчика: фото сразу пропадает у других, бот пишет причину, можно поставить другое.
- Решения: «Rasm mos» или «Mos emas» с причиной: лицо не видно, не один человек, не настоящее фото (`120`).
- Отказ: бот пишет причину и кнопку «Rasmni almashtirish»; в профиле видна причина.
- Удаление данных стирает фото и его статус (`30`).

## Кто видит фото попутчика

- **Только другие попутчики** той же поездки с подтверждённой бронью, сразу, пока команда не сказала «Mos emas» (G51).
- Водитель не видит фото попутчика никогда: ни до брони, ни после.
- В Mini App водителя открывается только своё фото, кем бы человек ни был раньше (попутчик старой поездки, сотрудник команды). Права команды действуют только в админке (решение владельца 17.10.2026, урок №310).
- **Модераторы** видят фото всегда: для проверки и жалоб (`17`).
- **Сделано в G46:** блок «Hamrohlaringiz» на брони попутчика: имя и фото других попутчиков, пока поездка впереди или идёт. После поездки там только имена: по ним выбирают, на кого жалоба (`17`). Сервер: `GET /passenger/bookings/:id/riders`.

## Требования к фото

- Только передняя камера, без галереи (решение владельца 17.10.2026; раньше галерея была разрешена, `118`).
- Лицо хорошо видно.
- Без тёмных очков и маски.
- В кадре нет других людей.
