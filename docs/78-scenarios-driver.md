# 78. Сценарии водителя

> **Кратко:** все пути водителя (часть каталога `76`). Задача водителя: заполнить пустые места и разделить расходы на дорогу. Проверка: файл стенда `e2e/stand/...`, unit-тест или «нет» (пробел, в работе G27).
