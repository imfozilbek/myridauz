# 01. Обзор проекта

## Что такое Rida

- **Rida** — сервис междугородних поездок (ride sharing) по всему Узбекистану.
- Цель — занять рынок междугородних поездок в Узбекистане.
- Домен: `myrida.uz`.

## Продукт

- Telegram-боты и Telegram Mini App (подробно — `02-architecture.md`).
- Telegram-каналы с поездками (формат пока не решён — `10-open-questions.md`).
- Лендинг на `myrida.uz` — в самом конце.

## Язык

- Продукт — **только на узбекском языке** (латиница).
- Архитектура с первого дня готова к новым языкам — `13-i18n.md`.
- Это касается всего, что видит человек: 3 бота, 3 Mini App (включая админ),
  каналы, уведомления, ошибки, лендинг.
- Русские названия кнопок в документах — только для объяснения.
  В продукте — узбекский текст.
- Код, имена в коде и комментарии — на английском.
  Документация в `docs/` — на русском.

## Бизнес-модель

- Заработок — **с водителей**.
- Rida — информационная площадка. Rida **не вмешивается** в договорённости
  между водителем и пассажиром.
- Модель оплаты пока не выбрана — `10-open-questions.md`.
- Если продавать цифровые услуги внутри бота, по правилам Telegram,
  скорее всего, нужны Telegram Stars.

## Ограничения

- Только бесплатные ресурсы: Telegram + Cloudflare
  (подробно — `03-tech-stack.md`).

## Юридический риск

- Перевозка пассажиров в Узбекистане может требовать лицензии.
- Позицию «мы только информационная площадка» нужно подтвердить у местного
  юриста до запуска монетизации.
