## Отклонено с причиной

| Что | Причина |
|---|---|
| A14: поддельная аналитика | Аналитика анонимная (`29`). Подделка только нарочным скриптом, есть лимит по IP, сигнал не чаще раза в 6 часов. Защита подписью меняет замысел приватности |
| U13, часть: блок только по телефону (другой Telegram) | Срок блока в ответе ошибки требует смены формата ошибок API; блок по ID теперь со сроком |
| Двое скрыли человека из поиска в одну секунду | Вред: одно лишнее сообщение. Защита требует новой отметки в базе |
| Чужой `sessionId` звонка | Id сессий Realtime случайные, их знают только две стороны звонка; звонить может только сторона чата |
| Повторный вход по билету сокета | Билет подписан на человека и чат, живёт 60 секунд; одноразовый билет требует хранилища на каждый вход |
| Две поездки или два места с двух телефонов в одну секунду | Главная кнопка держит одно действие за раз; лишнее водитель или попутчик отменяет, комиссия возвращается |
| Два принятых предложения одной заявки | Только с двух телефонов; лишнее место отменяется с возвратом комиссии |
| Владелец блокирует владельца или себя | Владельцы доверенные (1 или 2 человека), блок с подтверждением, снимает другой владелец; защита требует нового текста |
| Две правки кошелька владельцем сразу | Кнопка держит одно действие за раз; итог виден в журнале |
| Возврат по «Kelmadi» после удаления водителя | Деньги принадлежат водителю; закрытый кошелёк никому не виден |
| Telegram повторил нажатие или сообщение | Webhook отвечает быстро; кнопки ботов пишут условно |
| Повтор задачи напоминания | Очередь повторяет задачу только при сбое; отправка последний шаг |

- Двойной счёт входов по рекламной ссылке: ключ `ad_joins` (code, user_id) и `ON CONFLICT DO NOTHING` не дают второй записи.

- Блок модератора в «Jamoa» и открытие дела × решение: уже закрыты M10 и `01e4951`.
