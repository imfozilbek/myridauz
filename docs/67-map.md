# 67. Карта в Mini App: точка посадки попутчика

> **Кратко:** Попутчик выбирает точку посадки на карте внутри Mini App (G22, решение владельца 30.09.2026). Карта Узбекистана из OpenStreetMap лежит в нашем R2 и отдаётся через API. Внешних сервисов нет. Библиотека MapLibre: исключение из `19`, только на экране карты.

## Как это видит человек

- Бронь подтверждена: в брони есть «Xaritada tanlash».
- Карта открывается у выбранной точки, у точки встречи водителя или в центре города отправления.
- Булавка стоит в центре. Человек двигает карту, потом «Shu yerda».
- «Mening joylashuvim» ведёт карту к месту, где человек стоит. Нужно разрешение в Telegram (Bot API 8.0); в старом клиенте спрашивает браузер.
- Водитель сразу видит точку в брони и получает сообщение бота (как раньше из бота).
- Карта не загрузилась: «Xarita yuklanmadi», «Qayta urinish» и подсказка отправить место через бота. Бот остаётся запасным путём (`14`).
- Внизу подпись «© OpenStreetMap»: её требует лицензия ODbL.

## Первая загрузка

- Карта попадает в R2 только после запуска workflow «Map data» владельцем (GitHub → Actions → «Map data» → Run workflow, ветка `main`). До этого экран карты показывает «Xarita yuklanmadi» и путь через бота.

## Как обновить карту

1. В `packages/contracts/src/map.ts` поменять `MAP_ARCHIVE` на дату данных новой сборки в копии. Если дата не совпала, скрипт падает и пишет нужное имя.
2. PR, слияние, деплой из main.
3. В GitHub запустить workflow «Map data» (только с main, через Environment `production`, `32`).
4. Скрипт `pnpm map-data --brand=rida`: сверяет дату, вырезает Узбекистан, проверяет размер (не больше 300 МБ на один put), кладёт файл и шрифты в R2.

Новое имя файла: старые части в кэше никогда не смешиваются с новыми.

## Как устроено

- **API:** `GET /map/<файл>.pmtiles` отдаёт только часть файла (заголовок `Range`, не больше 2 МБ), `GET /map/fonts/<шрифт>/<диапазон>.pbf` отдаёт шрифт. Публично: данные OSM, о людях ничего. CORS только для Mini App.
- **Кэш:** часть, прочитанная из R2 один раз, лежит в кэше Cloudflare; телефону `Cache-Control: immutable` на неделю.
- **Точка:** `POST /passenger/bookings/<id>/pickup`. Только своя бронь, только подтверждённая, только точка в Узбекистане (граница OSM с запасом 3 км, `contracts/uzbekistan.ts`). Бот идёт тем же путём.
- **Mini App:** MapLibre и PMTiles грузятся отдельным куском (289 КБ в сжатом виде) только при открытии карты. Обёртка в `packages/ui/src/map`, стиль светлый (`20`), булавка цвета бренда.
- **Тесты:** unit на подделке карты (jsdom не рисует WebGL); e2e в настоящем браузере на куске карты Ташкента (`e2e/fixtures/map`, 2 МБ).

## Нагрузка (подробно `61`)

- Одно открытие карты: около 30 запросов к Worker (заголовок, каталоги, плитки, шрифты, движение карты).
- 600 броней в день: около 20 000 запросов Worker в день. R2: не больше 0,6 млн чтений в месяц при лимите 10 млн, хранение 0,25 ГБ из 10 ГБ.
