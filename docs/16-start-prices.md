# 16. Стартовые цены (черновик)

**Статус: черновик Claude. Владелец должен проверить.**
Эти цены — источник №3 рекомендации (формула), см. `09-marketplace-and-pricing.md`.

## Формула (разделение расходов)

```
доля за место = км × расход (л/км) × цена топлива / (мест + 1)
максимум      = доля за место × 1,5
```

## Параметры (настройки в админке)

| Параметр | Значение | Источник |
|---|---|---|
| Топливо | Бензин | Допущение, см. вопрос ниже |
| Цена бензина | ~18 300 сум/л | GlobalPetrolPrices, 21.09.2026 |
| Расход | 8 л / 100 км | Типичный седан (Cobalt, Gentra) |
| Мест для попутчиков | 3 | Типичный седан |
| Итого на 1 место | ~366 сум/км | 0,08 × 18 300 / 4 |
| Коэффициент максимума | 1,5 | Решение владельца (как BlaBlaCar) |
| Диапазон рекомендации | −10% … +10% от доли | Округление до 5 000 сум |

## Вопросы к владельцу

- Считать по бензину или по метану? Многие машины ездят на метане
  (~5 800 сум/м³). Тогда доля расходов будет примерно в 3 раза ниже,
  а максимум — сильно ниже рыночных цен. Совет: считать по бензину.
- Проверить цифры по реальным ценам на рынке.
