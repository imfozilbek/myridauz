## Что сознательно не делаем

| Идея | Почему нет |
|---|---|
| Места, цена и комментарий на одном экране проверки | Против «один экран: одно действие» (`19`); K3 и так даёт 3 тапа повторно |
| Заявка попутчика без шага цены | Цена: главный выбор попутчика, его надо увидеть |
| Одобрение заявки водителя в 1 тап | Сверка номера машины: защита людей (`50`) |
| Точка высадки по умолчанию | Ошибка точки хуже лишнего тапа |
| Строки плотнее, чем у Telegram | «Крупно» и родной вид Telegram (`19`, `21`) |
| «Oxirgi yoʻnalish» при живых поездках (K4) | Лишняя строка на главном экране; есть главная кнопка «Safar eʼlon qilish» |
| Убрать «Qachon» на проверке поездки | В маршруте только время, без даты: дата нужна |
| Убрать тексты о деньгах и безопасности | Это доверие; только сокращаем |
