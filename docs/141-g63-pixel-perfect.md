# 141. G63: сверка Pixel Perfect экранов водителя

> **Кратко:** все экраны G63 сверены с макетами `goals/g63/` попиксельно, в масштабе макета (1,5 для g63/1, 2, 3; 1,25 для g63/4, 5). Листы сверки (макет, код, наложение, карта разницы, номер на каждом отличии) и таблицы по номерам владелец получил 08.10. Всё, что код может повторить, совпадает до 0,5 css px. Остались только: шрифт (цель G73), тестовые данные, споры макетов между собой и вопросы владельцу ниже.

## Как сверял

| Что | Как |
|---|---|
| Макет | вырезка каждого телефона из `goals/g63/*.png` в родном масштабе |
| Код | Playwright, 360 × 760, `deviceScaleFactor` как у макета, данные и время макета: `e2e/g63-publish-pixel.spec.ts`, `g63-trip-pixel.spec.ts`, `g63-after-pixel.spec.ts` |
| Разница | рамка с номером на каждом отличии (листы для владельца, урок №160) |
| Размеры `121` | `e2e/g63-sizes-screenshots.spec.ts`, `g63-after-sizes-screenshots.spec.ts`, проверки 320/375/430 в `g63-trip-pixel.spec.ts` |

## Что исправлено сверкой (главное)

- Публикация: иконки строк на целом пикселе, степперы и число мест по макету, переключатель 42 × 24, «Xaritada ›», булавка на маленькой карте (30 px; на карточках встречи 34 px).
- «Qanday band qilinadi?»: заголовок 22 px. Раньше правило было написано для `h2`, а TelegramUI рисует `h3` (урок №163).
- «Mening safarim»: кнопка «Havolani yoʻlovchilarga yuborish» в одну строку на 320 … 430 px; плашки, просьбы, ряды попутчиков, карточка поездки по макету.
- Встреча и «после поездки»: радиусы как на макете; рамки 2,5 и 3,3 px тенью (Chrome рисует рамку целыми css px); звёзды без обводки.
- Новые токены (`20`): `successBright`, `textSecondary`, `neutralPale`, `neutralPaleText`.
